# 学习助手作为应用默认首页设计

## 背景

当前 `/app` 加载 `DashboardView.vue`，主要展示欢迎语、占位统计和学习模块快捷入口。学习助手已经承担对话、学习资产整理和跨应用导航职责，继续保留独立仪表盘会增加一次没有明显收益的跳转。

## 目标

- 用户访问 `/app` 时直接进入学习助手。
- 登录成功、公共首页“进入学习”、个人中心返回及其他现有 `/app` 入口统一落到学习助手。
- 保持 `/app/assistant` 为学习助手唯一的规范地址，避免同一页面存在两套路由状态。
- 删除旧仪表盘页面，不保留隐藏入口。

## 路由设计

`/app` 继续使用 `AppLayout.vue` 作为父路由。空子路由不再加载 `DashboardView.vue`，改为重定向到命名路由 `LearningAssistant`。

重定向需要保留原请求的 query 和 hash，使带参数的 `/app` 链接不会静默丢失上下文。最终浏览器地址为 `/app/assistant`。

`/app/assistant` 的现有组件、路由名称和 `immersive` 元数据保持不变，现有收藏、历史记录及直接链接继续有效。

## 删除范围

- 删除 `web/src/views/DashboardView.vue`。
- 删除路由中的 `Dashboard` 页面注册和对应的动态导入。
- 不修改公共网站首页 `web/src/pages/Home.vue`；其 `/app` 主入口通过重定向进入学习助手。
- 不修改写作、翻译、词汇、听力、口语和个人中心的独立路由。

## 导航行为

- 公共首页“进入学习” → `/app` → `/app/assistant`。
- 普通用户登录成功 → `/app` → `/app/assistant`。
- 个人中心“返回” → `/app` → `/app/assistant`。
- 管理员鉴权回退到业务端 → `/app` → `/app/assistant`。
- 无学段用户仍优先进入 `/app/stage-setup`；完成设置后若返回 `/app`，再进入学习助手。

## 错误与兼容处理

本次调整不改变 API、鉴权或持久化结构。若学习助手加载远端会话失败，继续使用现有助手页错误和重试机制；路由层不增加新的错误状态。

## 测试与验收

1. 路由测试确认 `/app` 空子路由重定向到 `LearningAssistant`。
2. 路由源码不再引用 `DashboardView.vue` 或 `Dashboard` 路由名称。
3. 现有 `/app/assistant` 路由测试继续通过。
4. 前端完整构建通过。
5. 浏览器验证访问 `/app` 后地址变为 `/app/assistant`，助手侧栏、会话区和输入框正常显示。

## 非目标

- 不重新设计学习助手内容区。
- 不调整其他业务模块的路由结构。
- 不新增新的首页、统计页或导航状态源。
