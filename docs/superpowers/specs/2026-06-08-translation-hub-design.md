# 翻译中心 Hub 首页设计

## 当前结论

`/app/translation` 首版先重做为“翻译中心 Hub”，不直接进入沉浸式阅读器。Hub 负责素材发现、继续学习、我的翻译记录和新建翻译入口；沉浸式阅读、PDF 高质量解析和考试翻译工作台作为后续从 Hub 进入的二级页面实现。

产品差异点不是通用翻译，而是学习型翻译：按用户学段推荐素材，把英文材料转化为笔记、词汇、句型、复习卡片和写作素材。

## 背景

当前翻译页仍偏向普通文本翻译。用户希望翻译模块能成为独立学习中心：用户可以找到经济学人、外刊新闻、学术期刊、考试材料、技术文档等素材，也能看到自己翻译过的内容和学习笔记。

主流翻译工具通常强调“把内容翻译出来”。PEAI 的定位应强调“把内容变成英语学习资产”，并和学段、考试、写作积累、笔记复习联动。

## 范围

本文覆盖：

- 翻译中心 Hub 首页的信息架构。
- Hub 首版模块、交互和视觉原则。
- 新建翻译入口的首版边界。
- 素材库、继续学习、我的翻译和右侧学习摘要。

本文不覆盖：

- 沉浸式双语阅读工作台实现。
- PDF 高质量解析实现。
- OCR、文件解析、翻译会话后端接口。
- 网页抓取。
- 真实素材版权接入和外部内容抓取。

## 页面结构

### 顶部

顶部只放核心入口，不做大 Hero。

- 标题：`翻译中心`
- 副标题：`找到素材，继续阅读，整理你的双语学习笔记`
- 主按钮：`新建翻译`

`新建翻译` 打开下拉或弹窗，配置不常驻页面：

- 上传 PDF / TXT / MD。
- 粘贴文本。
- 模式：沉浸阅读 / 考试翻译。
- 开始按钮：`开始沉浸式翻译`。

考试类型不在此处重复选择，后续由用户学段和材料识别决定。

### 继续学习

首屏重点展示最近 3 个翻译项目。卡片包含：

- 封面或来源图标。
- 标题和副标题。
- 来源类型：PDF / 用户导入 / 素材库。
- 模式：沉浸阅读 / 考试翻译。
- 进度：页码、段落或题目进度。
- 笔记数量。
- 标签：有笔记、考试翻译、写作素材等。
- 操作：`继续阅读`。

### 素材库

素材库用于体现 PEAI 的学习策划能力，而不是简单链接集合。

首版类别：

- 经济学人。
- 外刊新闻。
- 学术期刊。
- 考试材料。
- 技术文档。
- 用户导入。

每个类别卡片展示：

- 适合能力：阅读、写作素材、词汇积累、考试拆题等。
- 难度。
- 预计阅读时长。
- 素材数量。

外部报刊和期刊首版不抓取全文。只做来源入口、学习推荐和用户导入路径；项目自有或公开授权素材才可内置正文。

### 我的翻译

我的翻译用于管理用户已创建的翻译学习记录。

筛选项：

- 全部。
- 阅读中。
- 已完成。
- 有笔记。
- 考试模式。

列表字段：

- 标题。
- 来源类型。
- 翻译模式。
- 更新时间。
- 笔记数量。
- 进度。
- 状态。
- 操作：继续阅读 / 查看笔记。

### 右侧栏

右侧栏保持轻量，服务学习回访。

- 今日推荐：根据学段、素材类型和学习目标推荐。
- 我的笔记摘要：翻译篇数、阅读时长、笔记数量、重点词汇、句子收藏、复习卡片。
- 最近笔记：最近整理的词汇、句型、文章笔记。
- 新手引导：上传一篇文章、从素材库选一篇、继续上次阅读。

## 业务规则

| 规则 | 说明 | 影响 |
| --- | --- | --- |
| Hub 首页不展示常驻上传框 | 上传、粘贴、模式选择放入 `新建翻译` 弹窗或下拉 | 保持页面沉浸和仪表盘感 |
| 快速翻译不进入 Hub 主流程 | 一句话/短段翻译由 AI 助手承接 | 翻译页聚焦长材料学习 |
| 考试类型不重复配置 | 使用用户已设置的学段，后续结合材料类型识别 | 减少配置感 |
| 素材库不抓取外部全文 | 外刊、期刊首版只做入口和推荐，不存储版权正文 | 降低版权和登录态风险 |
| 首版允许 mock 数据 | Hub UI 先用前端数据跑通体验 | 后续再接真实接口 |

## 状态和边界

- 正常状态：有继续学习记录、素材分类、我的翻译列表和右侧统计。
- 空状态：没有翻译记录时，引导用户新建翻译或从素材库选择。
- 异常状态：素材推荐或历史记录加载失败时，保留新建翻译入口。
- 权限不足：未登录用户由现有路由守卫处理。
- 数据缺失：字段缺失时展示保守占位，不显示破碎 JSON 或空白卡片。

## 验收方式

- `/app/translation` 首屏展示翻译中心 Hub，而不是普通左右文本翻译器。
- `新建翻译` 入口清晰，但配置不常驻页面。
- 继续学习、素材库、我的翻译、右侧栏四个区域完整。
- 页面体现学习型翻译特色：学段推荐、笔记、词汇、句型、写作素材、考试翻译等。
- 桌面端布局稳定，移动端不重叠。
- 前端构建通过。

## 合并判断

Hub 首页是低风险前端首版，可以在独立分支完成并验证后合并到 `main`。后续沉浸式阅读、PDF 解析、OCR 和翻译会话后端属于更高风险能力，应拆分独立任务继续实现。
