# 个人中心档位标签与动态 Token 摘要设计

## 目标

精简个人中心“订阅与用量”页面，把当前档位放回用户身份区域，并让
AI Token 卡片顶部的数字与“每日 / 每周 / 累计”视图保持一致。

本次只调整现有个人中心的信息层级与前端状态共享，不新增接口、数据表、
图表依赖或支付能力。

## 当前问题

1. 当前档位使用一整张大卡片，占据订阅页首屏，但信息只有档位、有效期和
   当期用量，视觉权重过高。
2. 用户身份区域没有显示会员档位，用户需要进入订阅页才能确认当前权益。
3. AI Token 卡片左侧同时出现眉题、标题和说明，右侧又显示累计数字，标题区
   信息密度过高。
4. Token 顶部数字始终显示过去一年累计值，切换“每日 / 每周”后没有同步改变
   统计口径。
5. 个人中心头部和订阅区如果分别请求订阅状态，兑换后容易出现短暂不一致。

## 最终界面

### 用户身份区

- 在昵称和编辑按钮之间放置当前档位小标签，例如 `Free`、`Basic`、`Pro`、
  `Premium`。
- 标签使用个人中心现有绿色体系、紧凑圆角和弱背景，不与昵称争夺主视觉。
- 标签是可聚焦按钮，支持鼠标悬停、点击和键盘聚焦。
- 标签展开一个只读浮层，显示档位名称和有效期：
  - Free：优先使用订阅开始时间；该字段为空时使用用户注册时间作为开始，
    结束显示“长期有效”。
  - 付费档：使用后端现有 `currentPeriodStart` 和 `currentPeriodEnd`。
  - 开始时间缺失时显示“生效时间待同步”，不伪造日期。
- 浮层不承载兑换、升级或支付操作；这些行为仍保留在“订阅与用量”页。

### 订阅与用量页

- 页面标题从“当前权益与兑换码”改为“订阅与兑换码”。
- 删除原来的大尺寸当前档位卡片及其 `0 / 10K` 配额摘要。
- AI Token 活动卡片直接跟在页面说明之后。
- 兑换码表单和 Basic / Pro / Premium 套餐卡片保持原有功能与顺序。
- 当前付费档仍通过套餐卡片的激活样式标识。

### AI Token 卡片标题区

- 左侧只保留一行标题“AI Token 活动”，删除“过去一年”眉题和产品能力说明。
- 右侧保留大数字，但数字和标签随视图切换：
  - 每日：今天的 Token 总量，标签“今日 Token”。
  - 每周：当前自然周周一至今天的 Token 总量，标签“本周 Token”。
  - 累计：当前查询区间（过去一年）的总量，标签“累计 Token”。
- 当前自然周与下方每周方块视图使用同一套周一至周日聚合，避免标题数字和
  图表口径不一致。
- 每日热力图、每周 53 × 7 方块矩阵、累计自然月柱状图和用量构成保持不变。

## 数据与组件边界

### 单一订阅状态

`PersonalCenterPage.vue` 在加载用户资料时并行加载当前订阅状态，并持有个人
中心唯一的 `SubscriptionStatus`。

- 头部档位标签直接消费该状态。
- `SubscriptionSection.vue` 通过 prop 接收该状态，不再重复请求
  `/api/subscription/me`。
- 兑换成功后，`SubscriptionSection.vue` 向父页面发出更新后的订阅状态；
  父页面更新同一个引用，头部标签和套餐激活态同步刷新。
- 套餐列表仍由 `SubscriptionSection.vue` 加载，因为它只服务订阅页。
- 用户资料或订阅状态任一请求失败时，另一部分仍可独立显示；订阅状态失败时
  暂不渲染档位标签，并沿用现有错误提示。

### Token 摘要

`AiUsageActivityPanel.vue` 继续只请求一次过去一年的日粒度活动数据。

- 今日值从日期等于统计时区“今天”的日 bucket 获取；缺失 bucket 视为 0。
- 本周值复用 `buildWeeklyUsage` 生成的最后一个、包含今天的自然周周期。
- 累计值使用接口返回的 `activity.total`。
- 摘要数字使用纯函数生成，组件只负责根据当前 mode 渲染。

## 响应式与无障碍

- 档位标签跟随昵称行换行规则，不扩大头部最小宽度。
- 有效期浮层在窄屏时固定靠标签左侧对齐，并限制在可视区域内。
- 标签具备明确的 `aria-label`、`aria-describedby` 和键盘焦点样式。
- 浮层内容为只读补充信息，不截获 Tab 顺序。
- Token 模式按钮继续使用 tab 语义；摘要变化与选中 tab 同步。

## 测试与验收

### 自动测试

- Free 使用注册时间到“长期有效”。
- 付费档使用订阅周期起止时间。
- 缺失开始时间返回“生效时间待同步”。
- 每日摘要只取今天 bucket。
- 每周摘要取当前自然周总量。
- 累计摘要取整个活动区间总量。

### 浏览器验收

1. 姓名旁显示当前档位小标签。
2. 悬停、点击和键盘聚焦标签均能读取有效期。
3. 兑换会员码后，头部标签和套餐激活态同时更新。
4. 订阅页不再出现大档位卡片。
5. 每日、每周、累计切换时，右上数字和“今日 / 本周 / 累计 Token”同步变化。
6. 下方三种图表、详情交互、兑换码和套餐卡片没有回归。
7. 390px 下不产生页面级横向溢出，浏览器控制台无新增错误。
