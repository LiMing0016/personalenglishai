# PEAI 统一单层宽导航设计

日期：2026-07-21

## 背景

旧应用首页已移除，`/app` 进入学习助手。当前学习助手与写作等页面使用不同的左侧导航结构，用户从学习助手进入写作需要先展开侧栏、再点击 PEAI、再选择写作，入口较隐蔽；其中“首页”会重新进入学习助手，形成语义循环。

## 目标

- 使用一套全站一致的左侧导航连接学习助手、写作、翻译、阅读、听力和口语。
- 让跨应用入口持续可见，不再依赖 PEAI 下拉菜单。
- 在同一侧栏中展示当前应用的局部操作，避免叠加第二条导航栏。
- 保持现有 PEAI 绿色、浅色背景、圆角和线性图标语言。
- 在桌面端提高可发现性，在小屏幕上保护写作和学习画布的内容空间。

## 选定方案

采用 C 方案：单层宽导航。

- 桌面端侧栏宽度保持在 208–218px。
- 侧栏上半部分固定展示全局学习应用。
- 侧栏下半部分根据当前应用展示局部空间操作。
- 底部固定展示个人中心入口。
- 删除“首页”入口和 PEAI 应用下拉菜单。
- 小屏幕自动收敛为 72px 图标栏，局部操作通过展开侧栏访问。

## 信息架构

### 全局学习应用

顺序固定：

1. 学习助手
2. 写作
3. 翻译
4. 阅读
5. 听力
6. 口语

当前应用使用轻背景、左侧强调线、图标和文字字重共同表达，不只依赖颜色。

### 局部空间

学习助手空间：

- 新聊天（唯一绿色实心主按钮）
- 搜索对话
- 最近对话
- 文件夹
- 归档

写作空间：

- 新建作文（唯一绿色实心主按钮）
- 写作练习
- Dashboard
- 历史作文

其他应用按相同结构提供各自的页面级入口；没有局部入口时只显示全局应用和个人中心。

## 组件边界

### UnifiedAppSidebar

负责全局应用导航、当前路由高亮、响应式折叠、个人中心和局部插槽，不持有业务数据。

输入：

- 当前路由
- 当前应用标识
- 局部导航配置
- 主操作配置
- 折叠状态

输出：

- 路由跳转
- 主操作事件
- 展开/收起事件

### AppNavigationList

只渲染全局应用列表和当前项状态，使用项目现有图标资源。

### ContextNavigation

按当前应用渲染局部入口；学习助手继续复用现有对话、文件夹和归档能力，不复制状态源。

### AppLayout / AssistantPage

`AppLayout` 负责全站导航壳层。`AssistantPage` 只负责学习助手内容和对话状态，不再拥有一套独立的全局应用切换器。

## 状态与数据流

- 当前应用和选中项由 Vue Router 路由派生，不新增持久化状态。
- 展开/折叠沿用现有导航状态；如保留跨刷新偏好，继续使用现有存储键，不增加第二套键。
- 学习助手对话、文件夹和归档继续由现有组件与状态管理负责。
- 写作、翻译等业务数据和 API 不变。
- 导航失败时保留当前页面，不清理编辑器或对话状态。

## 视觉规则

- 整条侧栏最多一个绿色实心主按钮。
- 全局应用与局部空间通过分组标题、间距、字号和缩进区分。
- 选中项避免重复使用白色卡片和绿色圆点，采用轻背景与左侧强调线。
- 正文不小于 14px，辅助文字不小于 12px。
- 交互行高度不低于 44px。
- 图标使用项目现有 SVG/图标体系，不引入新图标库。

## 响应式行为

- 宽屏：显示 208–218px 单层宽导航。
- 受限宽度：显示 72px 图标栏，保留全局应用和主操作的可访问名称与悬停提示。
- 学习画布或写作编辑器空间不足时，侧栏以覆盖层展开，并提供遮罩关闭。
- 响应式切换不改变当前路由、草稿、对话或编辑器状态。

## 异常与边界

- 未识别路由不高亮任何应用，但导航仍可使用。
- 局部导航为空时不渲染空分组。
- 文案过长时单行截断并保留完整 `title` 或等效提示。
- 路由跳转失败时不触发业务状态重置。
- 键盘用户可以按视觉顺序访问全局应用、局部操作和个人中心。

## 验证

自动化验证：

- `/app` 仍默认进入学习助手。
- 全局应用链接在学习助手和写作页保持一致。
- 当前应用高亮由路由正确派生。
- 桌面与受限宽度下折叠策略符合预期。
- 删除旧“首页”链接和 PEAI 下拉切换器。

人工回归：

- 学习助手 ↔ 写作 ↔ 翻译双向切换。
- 展开/收起、遮罩关闭和浏览器前进后退。
- 对话、文件夹和归档功能不受影响。
- 写作草稿、编辑器、评分和恢复链路不受影响。
- 1280px、1024px 和更窄视口下不遮挡主要内容。
- 键盘焦点、焦点样式、文本溢出与 200% 缩放。

## 非目标

- 不修改后端接口和业务 DTO。
- 不重写写作编辑器、评分、语法或持久化链路。
- 不新增前端框架、状态库或图标依赖。
- 不恢复旧应用首页。
