# 学习 IDE 工作台设计

## 背景

当前 PDF 学习页面已经具备目录、PDF 阅读、Agent、锚点笔记和学习资产雏形，但右侧面板承担了过多职责：上下文、推荐译文、学习资产候选、Agent 聊天、笔记编辑都堆在同一区域，用户在选区后不知道下一步应该“问 AI”还是“写笔记”。

本设计将页面升级为 VSCode 风格的学习 IDE。PDF、锚点笔记、独立笔记和专题资产都作为工作区资源管理；右侧 Agent 作为跟随当前上下文的辅助面板，而不是所有内容的容器。

参考设计图：

- `docs/design/translation-learning-ide-workspace-vscode-v2.svg`

## 目标

1. 让页面看起来和使用起来像一个学习 IDE，而不是单个 PDF 阅读器。
2. 支持多 PDF、多笔记、多专题标签并行打开。
3. 同时支持锚点笔记和独立笔记。
4. 右侧默认保留 Agent，但当用户从 PDF 选区进入记笔记时，右侧切换为笔记工作台。
5. 让 Agent 成为笔记辅助能力：补充、整理、追问、生成复习卡，而不是抢占笔记编辑主位。

## 非目标

1. 本阶段不定义完整后端持久化模型。
2. 本阶段不实现跨 PDF 知识图谱或全局智能聚合。
3. 本阶段不把 PDF 阅读区整体改为深色，避免影响长时间阅读。
4. 本阶段不引入新的前端框架或组件库。

## 信息架构

### 顶部标签栏

顶部标签栏承载工作区内打开的资源：

- `PDF 数据结构 C++ 版`
- `笔记 起泡排序`
- `专题 排序算法`
- `+`

`+` 入口提供：

- 导入 PDF
- 新建独立笔记
- 从当前 PDF 选区新建锚点笔记
- 新建专题资产集合

### 左侧资源区

左侧采用 VSCode 式两层结构：

1. 活动栏：文档、书签、笔记、资产、搜索、设置。
2. Explorer：当前活动栏对应的资源树。

文档视图包括：

- 已打开资源
- 已导入 PDF
- 当前 PDF 目录
- 导入 PDF
- 新建笔记

笔记视图包括：

- 锚点笔记
- 独立笔记
- 最近编辑
- 待整理

资产视图包括：

- 已沉淀知识点
- 复习卡
- 专题集合
- 待整理候选

### 中间主工作区

中间主工作区只显示当前标签内容：

- PDF 标签：显示 PDF 阅读画布。
- 锚点笔记标签：显示完整笔记编辑器，并保留来源锚点。
- 独立笔记标签：显示完整笔记编辑器，不要求绑定 PDF。
- 专题标签：显示一组笔记、资产和来源 PDF 的聚合视图。

### 右侧 Agent 区

右侧不是固定聊天框，而是上下文辅助区：

- 默认状态：`Agent`
- PDF 选区记笔记状态：`笔记工作台`
- 笔记编辑状态：`笔记助手`
- 专题状态：`专题整理`

## 右侧状态设计

### 默认 Agent 状态

适用于未进入笔记编辑时。

结构：

1. 当前上下文：当前 PDF、页码、章节或当前笔记。
2. 快捷动作：解释选区、提取表达、生成笔记、整理资产。
3. Agent 对话流。
4. 输入框。

### 锚点笔记工作台状态

用户在 PDF 中选中文本并点击 `记笔记` 后进入。

结构：

1. 标题：`笔记工作台`
2. 上下文标识：`P25 · 选区`
3. 返回入口：`返回 Agent`
4. 分段标签：`写笔记 / 问 AI / 整理`
5. 锚点原文：展示选区文本、页码、章节。
6. 当前笔记：主编辑区。
7. Agent 辅助动作：补充解释、整理要点、生成复习卡。
8. AI 候选补充：AI 输出先进入候选区。
9. 操作：追加到笔记、保存笔记。

关键规则：

- 用户自己的笔记正文永远是主位。
- AI 内容默认不自动污染笔记正文。
- AI 输出先成为候选内容，用户确认后再追加。
- 保存后锚点笔记进入左侧笔记列表，并可以作为顶部标签打开。

### 笔记助手状态

当中间主区打开完整笔记标签时，右侧切换为笔记助手。

结构：

1. 当前笔记信息：标题、来源、关联锚点数量。
2. 结构化动作：补充解释、改写、压缩、生成复习卡、整理成专题。
3. Agent 对话流。
4. 追加到笔记或生成候选块。

### 专题整理状态

当中间主区打开专题标签时，右侧用于跨资源整理。

结构：

1. 专题上下文：专题标题、来源 PDF、关联笔记数。
2. 聚合动作：合并重复概念、生成复习路径、查找相关锚点。
3. Agent 对话流。

## 笔记类型

### 锚点笔记

锚点笔记必须绑定来源：

- documentId
- pageNumber
- chapterTitle
- selectedText
- bbox 或 elementId
- noteTitle
- noteContent
- createdAt / updatedAt

用户可从 PDF 选区创建，也可从当前页新建。

### 独立笔记

独立笔记不要求绑定 PDF：

- noteTitle
- noteContent
- tags
- relatedAssets
- createdAt / updatedAt

独立笔记用于专题整理、复习总结和跨 PDF 归纳。

### 共同能力

两类笔记都可以：

- 在顶部标签打开。
- 被 Agent 补充或整理。
- 生成学习资产候选。
- 加入专题集合。

## 交互流程

### 从 PDF 创建锚点笔记

1. 用户在 PDF 中选中文本。
2. 浮层出现：`当前选区 / 记笔记 / 问 Agent`。
3. 点击 `记笔记`。
4. 右侧从 Agent 切换为 `笔记工作台`。
5. 用户写笔记，或点击 Agent 辅助动作。
6. AI 回答进入候选区。
7. 用户点击 `追加到笔记`。
8. 用户点击 `保存笔记`。
9. 笔记进入左侧笔记列表，并可打开为顶部标签。

### 新建独立笔记

1. 用户点击顶部 `+` 或左侧 `新建笔记`。
2. 中间主区打开 `笔记 Untitled` 标签。
3. 右侧切换为 `笔记助手`。
4. 用户自由写笔记，可让 Agent 补充或整理。
5. 保存后进入左侧独立笔记列表。

### 引入其他 PDF

1. 用户点击顶部 `+` 或左侧 `导入 PDF`。
2. 导入成功后新 PDF 加入左侧文档树。
3. 新 PDF 可打开为顶部标签。
4. 右侧 Agent 上下文随当前 PDF 切换。

## 组件边界

建议后续实现时逐步拆分当前页面：

- `WorkspaceShell`：负责整体 IDE 布局。
- `WorkspaceActivityBar`：左侧活动栏。
- `WorkspaceExplorer`：资源树。
- `WorkspaceTabs`：顶部标签。
- `WorkspaceEditorArea`：中间主工作区。
- `PdfWorkspaceView`：PDF 阅读标签内容。
- `NoteEditorView`：完整笔记标签内容。
- `AgentContextPanel`：右侧默认 Agent。
- `NoteWorkbenchPanel`：锚点笔记工作台。

页面级状态应收敛为：

- openedTabs
- activeTabId
- activeSidePanel
- activeAgentMode
- activeSelectionContext
- draftNotes

## 数据流

1. PDF 选区由 `PdfLearningCanvas` 产生 selection context。
2. 页面接收 selection context 后决定是否打开右侧笔记工作台。
3. 笔记草稿进入统一 draftNotes 状态。
4. Agent 请求使用当前上下文，不直接修改笔记正文。
5. Agent 返回内容进入候选区。
6. 用户确认后候选内容追加到 draftNotes。
7. 保存时再进入实际笔记列表或后端接口。

## 错误和空状态

1. 没有选区时点击新建锚点笔记，应提示选择文本或改为当前页笔记。
2. Agent 请求失败时，候选区显示失败状态，不清空用户已写内容。
3. PDF 未解析目录时，左侧文档树显示“目录解析中”或“无目录”。
4. 导入 PDF 失败时，保留当前工作区状态并显示错误提示。
5. 笔记未保存切换标签时，应保留草稿。

## 视觉规则

1. 外框采用 VSCode 风格：深色标题栏、活动栏、Explorer、标签页和状态栏。
2. PDF 阅读画布保持浅色，避免深色 UI 影响 PDF 阅读。
3. 右侧 Agent/笔记面板跟随 IDE 深色外框，但编辑正文需要足够对比度。
4. 主色继续使用当前产品的 teal，作为学习行为和选区状态的强调色。
5. 卡片圆角控制在 8-12px，避免营销感。
6. 文案应偏工具化：`写笔记`、`问 AI`、`整理`、`追加到笔记`、`保存笔记`。

## 测试与验证

实现时至少覆盖：

1. 选区后 `记笔记` 能切换右侧为笔记工作台。
2. 默认右侧仍是 Agent。
3. 锚点笔记保存后出现在左侧笔记列表。
4. 独立笔记可从 `+` 或左侧入口创建。
5. 顶部标签可打开 PDF、笔记、专题。
6. Agent 候选内容不会自动写入笔记正文。
7. 浏览器缩小时，Explorer 和右侧面板不互相挤压覆盖。
8. `npm run build` 通过。

## 分阶段实现建议

### 第一阶段：布局重构

- 引入 VSCode 风格外框。
- 移动学习资产底部区到左侧资源区。
- 建立顶部标签栏视觉和状态。
- 右侧支持 Agent / 笔记工作台两种模式。

### 第二阶段：笔记体验

- 锚点笔记保存到当前前端状态。
- 独立笔记作为标签打开。
- Agent 候选内容追加到笔记。

### 第三阶段：资源沉淀

- 学习资产候选进入左侧资产视图。
- 支持从多个笔记整理专题。
- 支持多个 PDF 的资源树切换。
