# 个人中心前端重设计规格

## 背景

当前个人中心同时存在产品全局侧栏和个人中心二级侧栏，导航层级重复；内容命名以作文为中心，也无法承接学习助手、翻译、阅读和词汇等已经存在的产品能力。概览页的核心内容仍是四个数字和作文列表，缺少“下一步该做什么”的行动指引。

本轮先完成前端信息架构和视觉升级，暂不新增跨模块学习记录接口，也不接入正式支付。后续账号安全、兑换码和注销能力将在相同信息架构下继续实现。

## 目标

1. 保留现有产品全局侧栏，移除个人中心内部重复的左侧菜单。
2. 将个人中心导航改为内容区顶部横向页签。
3. 用跨产品语言重命名入口，不再把个人中心限制为作文资产。
4. 将用户选定的“动态学习时间线”作为学习概览的主组件。
5. 所有核心空状态都提供可执行入口。
6. 不展示伪造的跨模块统计或学习进度。

## 信息架构

个人中心页签固定为：

- 学习概览
- 学习记录
- 学习资产
- 能力画像
- 订阅与用量
- 账号安全

移除“邀请激励”。旧的 `tab=referral` 不再识别，回落到“学习概览”。

本轮沿用已有子页面实现：

- “学习记录”现阶段承载已有作文记录，后续接入统一学习事件流。
- “学习资产”现阶段承载已有作文资产，同时在概览中提供词汇、写作和翻译的快捷入口。
- “能力画像”现阶段仍以已有写作评测数据为基础，并通过文案明确数据来源。

## 页面结构

### 顶部用户区

- 左侧显示头像、昵称、学习阶段、注册时间和邮箱验证状态。
- 昵称和学习阶段继续支持原有编辑操作。
- 采用单一白色内容面板和细边框，不使用第二块侧栏。

### 横向页签

- 位于用户信息下方。
- 选中态使用品牌绿色文本和底部细线。
- 宽屏单行展示；窄屏允许水平滚动。
- 通过 `?tab=` 保持可分享和刷新后的状态。

### 动态学习时间线

以用户选定的第 2 稿为唯一视觉目标：

- 白色/极浅蓝背景、细蓝灰边框、轻微柔光。
- 横向三段：上次完成、现在继续、为你准备。
- 中间节点是视觉和操作焦点，使用绿色圆形书本图标。
- 主操作是“继续学习”，次操作为“开始写作”“新建翻译”。
- 右侧操作连接词汇复习。
- 使用 `lucide-vue-next` 的图标，不引入手绘 SVG 或图片替代图标。

数据规则：

- 最近作文记录存在时，左侧展示真实记录摘要和真实时间。
- 没有历史记录时，左侧展示“完成一次学习后会沉淀在这里”，不伪造日期和数量。
- 中间的学习计划是产品级入口，不伪造具体 Task 或完成状态。
- 本周节点使用已有 `studyDays` 做保守映射，最大展示 5 个节点。
- 词汇待复习数量没有统一接口时不展示虚构数字，只呈现“复习重点词汇”。

### 概览下半区

- 四项摘要沿用已有真实统计：累计作文、平均分、最高分、学习天数。
- 最近活动列表继续使用现有作文评测历史。
- 空记录时显示“开始第一次写作”按钮。
- 资产入口提供写作、词汇、翻译三个真实路由。

## 交互与状态

- 所有页签、主按钮、次按钮、资产入口均使用真实路由。
- 加载状态使用克制的骨架屏，避免布局跳动。
- API 失败时保留页面框架，并显示可继续使用的学习入口。
- 个人中心在 1024px 以下缩减留白，在 760px 以下将时间线改为纵向流程。
- 键盘焦点必须可见，按钮和页签保留语义化元素。

## 视觉原则

- 色彩：墨绿 `#047857` / 深海军蓝 `#0f2440` / 冷白 `#f7fafc`。
- 圆角：主面板 24px，卡片 18–22px，按钮 12–14px；不做无差别胶囊化。
- 阴影：仅用于主时间线的低透明度柔光。
- 字体：沿用项目系统字体栈；数字使用等宽数字特性。
- 图标：统一使用 Lucide，线宽保持一致。

## 后续功能接口边界

本轮不实现后端，但页面结构预留：

- 账号安全：服务端退出、重发验证邮件、绑定/换绑手机、修改密码后令牌失效、换绑邮箱、用户确认后立即注销。
- 注销数据：删除身份和认证信息，保留最小注销墓碑；为审计、订阅和业务一致性必须保留的数据需去标识化。
- 订阅：兑换码替代支付；兑换码支持后台批次生成、HMAC 存储、计划和时长、有效期、撤销、原子单次兑换和历史记录。
- 不保留可由普通用户调用的模拟购买入口。

## 验收标准

1. 页面中不存在第二个个人中心左侧菜单。
2. 不再展示“邀请激励”入口。
3. 六个横向页签可切换并能通过查询参数恢复。
4. 选定时间线组件在桌面和移动布局都可用。
5. 所有展示数字来自已有接口或明确的空状态。
6. 学习助手、写作、翻译和词汇操作均跳转到真实页面。
7. 前端类型检查和生产构建通过。
8. 浏览器设计 QA 无 P0/P1/P2 问题，根目录 `design-qa.md` 最终标记为 `passed`。
