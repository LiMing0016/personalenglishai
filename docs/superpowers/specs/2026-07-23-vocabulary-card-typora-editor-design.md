# 单词卡 Typora 式编辑器设计规格

## 背景

当前单词卡学习内容使用 Markdown 存储，但编辑界面仍表现为大型文本框或多个表单区块。这样虽然便于实现，却削弱了阅读连续性，也让用户产生“编辑一堆框框”的感觉。

本次设计将学习内容编辑升级为简化版 Typora 体验：用户面对的是一篇可直接编辑的学习文章，而不是 Markdown 源码表单。右侧目录负责章节定位，AI 仅作为章节级辅助能力出现。

## 目标

1. 保留 Markdown 作为学习内容的统一存储格式。
2. 默认提供所见即所得编辑，降低 Markdown 使用门槛。
3. 让编辑态与阅读态保持接近，减少模式切换带来的视觉跳变。
4. 支持快速定位例句、使用边界、易混辨析、记忆提示和个人笔记。
5. AI 调整只影响当前章节，避免覆盖整张单词卡。

## 非目标

- 本期不实现完整 Typora 的全部 Markdown 语法。
- 本期不提供左右分屏预览。
- 本期不把学习内容拆成大量独立表单区块。
- 本期不允许在学习内容编辑器中修改单词、音标、词性和核心词义。
- 本期不开放多人协同编辑和评论能力。

## 页面结构

### 顶部操作区

保持现有单词卡头部与操作栏，不重复展示学习内容操作。

- 单词名称和发音按钮。
- 阅读、编辑学习内容、重新生成。
- 主题选择。
- 自动保存状态。
- 退出编辑与保存。

保存操作只保留在顶部，不在正文底部重复出现。

### 中央编辑画布

- 正文画布宽度约为 `760px` 至 `820px`。
- 使用无边框白色画布，不显示大型输入框外框。
- 编辑排版尽量接近阅读态，包括标题层级、段落间距、列表和提示块。
- 当前编辑段落使用浅绿色背景或左侧细线提示，不把整个章节包裹成卡片。
- 页面保留足够留白，正文不会铺满可用宽度。

### 右侧吸附目录

目录固定在正文右侧并随页面滚动保持可见。

- 显示当前主题定义的章节。
- 当前章节使用绿色竖线和加深文字标识。
- 点击目录项平滑滚动到对应章节。
- 正文滚动时根据可见章节自动更新选中项。
- 较长标题使用单行截断并通过悬停提示展示完整标题。
- 目录底部提供“返回顶部”入口。

默认章节示例：

1. 例句
2. 使用边界
3. 易混辨析
4. 记忆提示
5. 个人笔记

## 所见即所得规则

### 基础语法

首期支持：

- 一级至三级标题
- 有序列表与无序列表
- 粗体与斜体
- 引用
- 行内代码
- 链接
- 分隔线

### 输入行为

- 用户输入 `# `、`## `、`### ` 后，当前行转换为对应标题。
- 用户输入 `- `、`* ` 或 `1. ` 后，当前行转换为列表。
- 用户输入成对的 `**`、`*` 或反引号后，内容按对应样式显示。
- 光标进入已格式化内容时，仅显示当前内容所需的 Markdown 标记。
- 在空标题或空列表项开头按退格，恢复为普通段落。
- 粘贴 Markdown 时直接解析为所见即所得内容。
- 用户仍可从“更多”菜单打开完整 Markdown 源码进行高级修复。

## 工具栏

工具栏默认隐藏，避免长期占据正文空间。

- 选中文字时，在选区上方显示浮动工具栏。
- 光标位于空段落时，可通过行首的加号打开插入菜单。
- 工具栏提供粗体、斜体、列表、编号、引用和链接。
- 工具栏不使用通栏容器，不改变正文宽度。

## AI 章节操作

每个章节标题在悬停或获得焦点时显示轻量操作：

- AI 调整本节
- 换一组内容
- 降低难度
- 结合当前主题
- 更多

规则：

- AI 请求只携带当前章节、核心词义和主题信息。
- AI 返回内容先显示差异预览，用户确认后替换当前章节。
- AI 操作不得覆盖其他章节和个人笔记。
- 请求失败时保留原内容和未保存编辑。
- 重新发起请求时取消旧请求，旧结果不得覆盖新结果。

## 自动保存与状态

- 用户停止输入约 800 毫秒后自动保存草稿。
- 顶部状态依次显示“正在保存”“已自动保存”或“保存失败”。
- 离开页面前若仍有未同步内容，需要提示用户。
- 手动保存用于创建明确版本点，并返回阅读态。
- 保存失败后保留本地草稿，允许重试。

## 数据边界

- 核心词义继续使用结构化 JSON，由独立入口编辑。
- 学习内容继续使用单一 Markdown 文档存储。
- 右侧目录由 Markdown 标题解析生成，不额外维护一份目录数据。
- 个人笔记是 Markdown 文档中的普通章节，可被用户持续补充。
- 主题 Prompt 决定首次生成的章节与内容，但不限制用户后续编辑。

## 响应式规则

- 宽屏：正文居中，目录位于右侧。
- 中等宽度：目录缩窄，仅显示章节名称。
- 小屏：右侧目录收起为顶部“目录”按钮，点击后打开抽屉。
- 移动端不保留悬停依赖，章节操作通过标题右侧更多按钮触发。

## 可访问性

- 所有工具按钮提供可读名称和键盘焦点样式。
- 目录当前项不能只依赖颜色区分。
- 编辑器支持键盘完成格式化、目录跳转和保存。
- 保存状态通过可访问状态区域播报。

## 验收标准

1. 页面默认不出现大型编辑框或多层卡片容器。
2. 阅读态与编辑态的正文宽度、层级和间距基本一致。
3. 输入常用 Markdown 语法后立即显示对应格式。
4. 右侧目录可点击跳转，并能跟随滚动更新当前章节。
5. 选中文字时出现浮动格式工具栏，失焦后隐藏。
6. AI 调整只改变当前章节，其他章节和个人笔记保持不变。
7. 自动保存失败不会丢失用户输入。
8. 桌面端和移动端不存在文字溢出、遮挡或不可达操作。

## Figma 交付范围

下一版 Figma 至少包含以下状态：

1. 默认编辑态：正文画布与右侧吸附目录。
2. 文本选中态：显示浮动格式工具栏。
3. 章节悬停态：显示章节级 AI 操作。
4. 移动端目录抽屉态。
