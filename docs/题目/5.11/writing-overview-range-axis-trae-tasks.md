# 写作总览筛选菜单与横坐标联动 Trae 实现题目

## 背景

写作 Dashboard 的“写作总览”已经使用 ECharts 展示组合图，但当前筛选体验和图表口径还需要继续打磨。

目标效果：

- 时间范围和写作模式使用菜单形式选择。
- 时间范围支持快捷选择和自定义开始 / 结束日期。
- 将“本月”替换为“近1年”。
- 图表底部横坐标必须和当前时间范围一致。
- 图表继续使用 ECharts，不允许退回静态 SVG 或手写假图。

默认口径：

- 时间范围：近30天。
- 写作模式：全部模式。
- 评分口径：按每篇最新评分。

## 题目 1：把统计口径改成菜单选择

### Prompt

把写作总览顶部的统计口径改成两个菜单：时间范围和写作模式。

要求：

1. 时间范围菜单支持：
   - 近7天
   - 近14天
   - 近30天
   - 近1年
   - 全部
   - 自定义范围
2. 写作模式菜单支持：
   - 全部模式
   - 自由模式
   - 考试模式
3. 菜单放在“写作总览”标题区域内部，不再放在外层页面顶部。
4. 页面顶部不要再保留一排独立的统计口径按钮。
5. 菜单样式保持当前米白 academy 风格，不能做成重型 tab。

### 验收标准

- 写作总览卡片内能看到“时间范围”和“写作模式”两个菜单。
- 点击时间范围能看到快捷选项和自定义日期区域。
- 点击写作模式能切换全部 / 自由 / 考试。
- 外层页面没有重复的筛选按钮。
- 移动端菜单不横向溢出。

## 题目 2：实现自定义日期范围

### Prompt

给时间范围菜单增加自定义开始日期和结束日期。

要求：

1. 自定义区域包含：
   - 开始日期
   - 结束日期
   - 应用日期范围按钮
2. 日期输入使用浏览器原生 `type="date"`。
3. 点击“应用日期范围”后，当前时间范围显示为自定义日期区间。
4. 如果用户选择的开始日期晚于结束日期，不要让页面报错。
5. 自定义日期变化后，写作总览副标题也要同步变化。

### 验收标准

- 自定义日期可以输入和应用。
- 副标题能展示类似 `04/12 - 05/12 · 全部模式 · 按每篇最新评分`。
- 无效日期不会导致页面崩溃。
- 菜单外点击后能关闭弹层。

## 题目 3：让 ECharts 横坐标跟随时间范围

### Prompt

修复写作总览图表横坐标，使它和当前选择的时间范围一致。

要求：

1. 继续使用 ECharts 组合图。
2. 横坐标生成规则：
   - 近7天：展示最近 7 天日期。
   - 近14天：展示最近 14 天日期。
   - 近30天：展示最近 30 天日期。
   - 近1年：展示最近 12 个月。
   - 自定义范围：短范围按天展示，超过 90 天按月展示。
   - 全部：可以先沿用 mock 趋势数据。
3. 图表数据可以继续用 mock 生成，但横坐标不能固定写死为 `05-10 / 05-17 / 06-14`。
4. tooltip 中展示的日期或月份要和横坐标一致。
5. 切换时间范围后，图表要重新渲染。

### 验收标准

- 选择“近1年”时，横坐标变成月份，不再显示近30天日期。
- 选择“近7天”时，横坐标只覆盖最近 7 天。
- 自定义日期短范围按天展示，长范围按月展示。
- tooltip 日期和当前横坐标口径一致。
- 图表仍然包含新增作文柱、评分次数柱、平均分折线、最高分标注。

## 题目 4：补测试与构建验证

### Prompt

为写作总览筛选和横坐标联动补充轻量测试。

要求：

1. 更新 `writingDashboardPrototype.test.ts`。
2. 测试至少覆盖：
   - 写作总览组件包含时间范围菜单。
   - 写作总览组件包含自定义日期输入。
   - 时间范围选项包含“近1年”。
   - 不再使用“本月”作为默认快捷项。
   - 图表存在根据当前范围生成展示数据的逻辑。
   - 图表监听自定义日期变化。
3. 保留现有 AppRail、Dashboard、首页拆分相关测试。
4. 不新增测试框架。

### 验收标准

- `node tests/writingDashboardPrototype.test.ts` 通过。
- `node tests/appRailChrome.test.ts` 通过。
- `npm run build` 通过。
- TypeScript 无编译错误。
- 没有新增图表库依赖。

## 推荐执行顺序

1. 先改时间范围和写作模式菜单。
2. 再接自定义日期范围。
3. 再改 ECharts 横坐标生成逻辑。
4. 最后补测试并跑构建。

- 不新增第三方 UI 组件库。
