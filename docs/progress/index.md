# 功能进度总览

## 当前结论

`docs/progress/` 只做一件事：让你按功能主线快速找到“当前实现了什么、还欠什么、怎么验收”。

进度不做复杂前端交互，直接在 Markdown 里维护。做完一个需求点，就在对应功能进度页里勾选验收项，并把状态改成 `✅ 已完成`。

## 维护方式

每条功能主线维护一篇进度文档。

- 需求拆解和 Trae 题单：放在仓库根目录 `tasks/`，它不属于 VitePress 文档站页面，需要在 IDE 或文件管理器里打开。
- 当前功能状态和验收清单：放在 [进度目录](/progress/)。
- 架构方案和长期设计：放在 [架构目录](/architecture/)。
- 产品规则和用户流程：放在 [产品目录](/product/)。

## 状态标记

| 状态 | 含义 |
| --- | --- |
| ⬜ 未开始 | 还没有进入实现。 |
| 🚧 进行中 | 正在实现。 |
| 🧪 待验收 | 代码已做，需要完整验收。 |
| ◐ 部分完成 | 有基础能力，但没有满足完整目标。 |
| ✅ 已完成 | 已实现并验收通过。 |
| ⚠️ 有问题 | 已实现但质量不达标，需要返工。 |
| ⏸️ 暂缓 | 当前不做，等待前置条件。 |

## 当前优先级

1. 验收文字主链路 v1：原 PDF 持久化、目录导航、文本选区、source chunks、引用跳转。
2. 增强 OCR 质量诊断：乱码、重复、低置信页和扫描版 token 选区。
3. 接入真正 LLM 讲解 Prompt 和更稳定的 embedding / rerank 检索。
4. 主链路稳定后，再做图片、表格、公式等高质量解析增强。
