# 学习资料

本目录用于存放项目学习笔记和基础技能资料，方便在文档站里集中查看。

当前建议先从 Markdown 语法开始，因为项目文档、任务说明、Agent 学习笔记和 API 说明都大量使用 Markdown。学习 OpenAI Structured Outputs 时，可以继续阅读 Jupyter 验证不同 Schema 的示例。

## 阅读顺序

| 顺序 | 文档 | 用途 |
| --- | --- | --- |
| 1 | [Markdown 常用语法](./Markdown常用语法.md) | 学习标题、列表、链接、代码块、表格、引用、Mermaid 和 VitePress 文档写法。 |
| 2 | [Jupyter 验证不同 Schema](./Jupyter验证不同Schema.md) | 在 Notebook 中验证写作教练不同阶段使用不同 Pydantic Schema 的效果。 |

## 维护规则

- 学习资料以“够用、可查、能直接复制”为目标。
- 示例优先贴近本项目文档写法。
- 新增学习页后，记得同步更新本页和 VitePress 侧边栏。
