# CEFR 文档

本目录记录 CEFR 在 PEAI 项目中的产品化使用方式、数据结构、RAG 知识库边界和后续落地建议。

当前文档：

- [cefr-project-guide.md](./cefr-project-guide.md)：CEFR 在 PEAI 中作为能力坐标系的总体使用指南。
- [cefr-companion-product-application.md](./cefr-companion-product-application.md)：基于 CEFR Companion Volume 2020 的项目化应用说明，覆盖用户能力图、写作评分、词汇分级、语法分层和学习规划。
- [cefr-rag-extraction-guide.md](./cefr-rag-extraction-guide.md)：从 CEFR Companion Volume 2020 中提炼适合 RAG 的中文知识条目、元数据结构和拆分策略。

使用原则：

- CEFR 在项目中作为能力坐标系，不作为官方认证。
- 考试评分仍使用各考试 rubric；CEFR 负责解释能力、组织学习路径和标注学习资源难度。
- 官方材料应以摘要、转述和结构化提炼方式进入项目，不做整书逐字翻译或全文 RAG。
