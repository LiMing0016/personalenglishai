# CEFR Companion Volume 2020 项目化应用指南

## 文档定位

本文件基于 `CEFR Companion Volume_eng_2020.pdf` 做项目化提炼，用于指导 PEAI 的用户能力图、写作评分解释、词汇分级、语法分层和学习规划。

这不是 CEFR 官方译文，也不是整书翻译。文档只保留对项目有用的结构、概念和可落地设计。

## 一句话理解 CEFR

CEFR 不是一本教材，也不是考试打分表。它是一套描述语言能力的通用框架，核心是用 `A1 / A2 / B1 / B2 / C1 / C2` 表示学习者能完成什么语言任务。

对 PEAI 来说，CEFR 最适合作为“能力地图”：

- 当前用户在哪个能力区间。
- 写作、阅读、听力、口语分别处于什么水平。
- 用户想达到下一级，还缺哪些能力。
- 单词、语法、作文任务和练习应该匹配什么难度。

## 章节级中文摘要

### Foreword / Preface

这部分说明 CEFR 的背景和 Companion Volume 的更新目的。对项目的价值是确认 CEFR 的定位：它服务教学、学习、评价和课程设计，不是单一考试产品。

项目启发：

- 产品文案应避免说“官方认证 CEFR 等级”。
- 可以说“基于 CEFR 能力描述的估计等级”。
- CEFR 适合作为多个模块之间的共同语言。

### Chapter 1: Introduction

第 1 章说明 Companion Volume 是对 2001 版 CEFR 的更新和扩展，重点是让框架更容易使用，并补充新的描述量表。

项目启发：

- PEAI 不需要一次性接入全量 CEFR。
- 第一版应先提取用户最能感知的能力维度：听、读、口语互动、口语表达、写作。
- 后续再逐步接入 online interaction、mediation 等复杂能力。

### Chapter 2: Key aspects of the CEFR for teaching and learning

第 2 章解释 CEFR 的核心思想：以行动为导向，关注学习者能在真实场景中做什么。它强调 `can do` 描述，而不是只看考试分数。

项目启发：

- 能力图应该使用“能做什么”的语言，而不是只显示分数。
- 评分结果可以从“扣了多少分”升级为“你现在能完成什么、还不能稳定完成什么”。
- 学习计划应围绕任务能力差距生成。

### Chapter 3: Communicative language activities and strategies

第 3 章是对项目最有价值的主体内容。它把语言活动拆成 reception、production、interaction、mediation。

项目可直接使用的维度：

| CEFR 分类 | 产品化名称 | PEAI 用途 |
| --- | --- | --- |
| Oral comprehension | 听力理解 | 后续听力画像 |
| Reading comprehension | 阅读理解 | 阅读材料难度、阅读能力图 |
| Oral production | 口语表达 | 后续口语输出能力 |
| Written production | 写作表达 | 写作评分解释、写作目标 |
| Oral interaction | 口语互动 | 对话、面试、日常交流 |
| Written interaction | 书面互动 | 邮件、留言、在线沟通 |
| Mediation | 转述与解释 | 翻译、总结、解释材料、跨语言表达 |

第一版建议只落地：

- Reading
- Writing
- Spoken interaction
- Spoken production
- Listening

Mediation 可以作为 PEAI 的高级能力方向，因为你的项目已有翻译、讲解、总结和学习助手对话。

### Chapter 4: Plurilingual and pluricultural competence

第 4 章强调多语言和跨文化能力。对当前 PEAI 来说，它不是第一阶段重点。

项目启发：

- 中英互译、英文解释中文问题、用中文学习英文，都可以理解为跨语言能力的一部分。
- 不建议第一版把这部分做成用户能力图主维度。
- 可在 Translation Agent 或 Learning Planner Agent 中作为高级补充能力。

### Chapter 5: Communicative language competences

第 5 章非常适合映射到你现有的写作雷达。它描述语言能力本身，包括词汇、语法、拼写、社会语言得体性、连贯、流利、主题展开等。

项目可映射：

| CEFR 能力项 | PEAI 写作雷达/评分项 |
| --- | --- |
| Vocabulary range | 词汇丰富 |
| Vocabulary control | 词汇准确 |
| Grammatical accuracy | 语法准确 |
| Orthographic control | 拼写与书写规范 |
| Coherence and cohesion | 连贯衔接 |
| Thematic development | 篇章结构 / 主题展开 |
| Sociolinguistic appropriateness | 语体得体 / 正式度 |
| Propositional precision | 表达准确 / 观点清晰 |

你的现有六维雷达可以保留，不要替换成 CEFR 六级。CEFR 用于解释“为什么这组能力大概对应 B1/B2”。

### Chapter 6: Signing competences

第 6 章是手语能力描述。当前 PEAI 是英语学习产品，不建议纳入第一版。

### Appendices

附录对产品化最有用，尤其是：

- Appendix 1：A1-C2 等级显著特征。
- Appendix 2：扩展自评表。
- Appendix 4：写作评估表。

项目启发：

- Appendix 2 适合做用户自评问卷和能力图。
- Appendix 4 适合做写作能力解释层。
- Appendix 1 适合做 A1-C2 的中文产品说明。

## A1-C2 等级含义

以下是项目内可用的产品化解释，不是官方逐字翻译。

| 等级 | 用户类型 | PEAI 中文解释 | 产品提示 |
| --- | --- | --- | --- |
| A1 | 初始使用者 | 能处理最基础的个人信息、简单句和熟悉场景。 | 重点是听懂、看懂、写出简单句。 |
| A2 | 基础使用者 | 能完成日常生活中的简单交流和短文本表达。 | 重点是稳定表达具体需求和简单经历。 |
| B1 | 独立使用者入门 | 能围绕熟悉主题表达观点、经历和基本理由。 | 这是从“会句子”到“能连贯表达”的关键阶段。 |
| B2 | 独立使用者进阶 | 能较清楚、详细地讨论较广主题，并支持观点。 | 这是多数考试写作和学术表达的核心目标区间。 |
| C1 | 熟练使用者 | 能处理复杂主题，表达清晰、结构严谨、风格得体。 | 重点是准确、自然、复杂表达和语体控制。 |
| C2 | 高熟练使用者 | 能非常精准、流畅、灵活地处理复杂文本和细微含义。 | 不等于母语者，但代表高度成功的学习者水平。 |

## 用户能力图设计

### 推荐页面结构

```text
能力雷达

1. CEFR 综合能力
   - Overall
   - Listening
   - Reading
   - Spoken Interaction
   - Spoken Production
   - Writing

2. 写作能力细项
   - 任务完成
   - 连贯衔接
   - 语法准确
   - 词汇丰富
   - 篇章结构
   - 表达多样

3. 下一步提升
   - 当前等级
   - 目标等级
   - 主要差距
   - 推荐训练
```

### 为什么要分两层

CEFR 的 `A1-C2` 是等级，不是雷达轴。`Listening / Reading / Spoken Interaction / Spoken Production / Writing` 才是能力维度。

你的现有写作六维雷达回答的是“写作内部哪里强、哪里弱”。CEFR 综合能力图回答的是“用户整体能力在哪”。两者不应混在一张雷达里。

### 能力图字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `user_id` | string | 用户 ID |
| `skill` | enum | `listening` / `reading` / `spoken_interaction` / `spoken_production` / `writing` / `overall` |
| `estimated_level` | enum | `A1` / `A2` / `B1` / `B2` / `C1` / `C2` |
| `level_modifier` | enum | `minus` / `standard` / `plus`，可选 |
| `target_level` | enum | 目标等级 |
| `confidence` | enum | `low` / `medium` / `high` |
| `evidence_type` | enum | `self_assessment` / `writing_evaluation` / `quiz` / `manual` / `mixed` |
| `evidence_summary` | string | 本次判断依据摘要 |
| `updated_at` | datetime | 更新时间 |

## 写作评分如何结合 CEFR

### 保留现有评分

PEAI 现有考试评分、作文评分和六维雷达继续保留。CEFR 不替代它们。

### 增加 CEFR 解释层

评分结果可以增加：

| 字段 | 含义 |
| --- | --- |
| `estimated_writing_cefr` | 本篇作文估计写作等级 |
| `cefr_reason` | 为什么接近这个等级 |
| `next_cefr_target` | 下一目标等级 |
| `learning_gap` | 从当前等级到目标等级的差距 |
| `training_actions` | 推荐训练动作 |

示例：

```text
本篇写作估计接近 B1+。
你已经能围绕熟悉主题写出连贯内容，但论证展开、复杂句控制和正式表达还不稳定。
如果目标是 B2，下一步应重点训练段落展开、连接表达和复杂句准确性。
```

### CEFR 与现有写作六维映射

| PEAI 维度 | CEFR 参考能力 | 解释用途 |
| --- | --- | --- |
| 任务完成 | Written production / Reports and essays | 是否完成题目要求和写作目的 |
| 连贯衔接 | Coherence and cohesion | 句子、段落和观点之间是否自然连接 |
| 语法准确 | Grammatical accuracy | 语法控制是否稳定 |
| 词汇丰富 | Vocabulary range | 表达资源是否足够 |
| 篇章结构 | Thematic development / Reports and essays | 观点是否展开，结构是否服务论证 |
| 表达多样 | Range / Sociolinguistic appropriateness | 句式、语体和风格是否成熟 |

## 词汇分级如何结合 CEFR

单词书适合进数据库，CEFR 标签作为字段。

### 推荐字段

| 字段 | 说明 |
| --- | --- |
| `word` | 单词或短语 |
| `cefr_level` | 估计等级 |
| `level_source` | `manual` / `estimated` / `imported` |
| `topic_tags` | 主题标签 |
| `exam_tags` | 考试标签 |
| `productive_use` | 是否建议主动用于写作/口语 |
| `receptive_use` | 是否只建议先认识 |
| `collocations` | 搭配 |
| `common_mistakes` | 常见误用 |

### 产品用法

- A1-A2：优先解释基本义和简单例句。
- B1：加入常见搭配和熟悉主题表达。
- B2：强调准确选词、正式表达和观点支撑。
- C1-C2：强调语体、细微差异、抽象表达和地道搭配。

## 语法分层如何结合 CEFR

CEFR 不给项目一套可直接照搬的英语语法课程表。PEAI 应把 CEFR 作为难度分层参考，再结合自己的语法 taxonomy。

### 项目第一版分层

| 等级 | 语法教学重点 |
| --- | --- |
| A1 | 基本句型、be 动词、一般现在时、基础疑问句、简单否定 |
| A2 | 一般过去时、将来表达、比较级、常见介词、基础并列句 |
| B1 | 现在完成时、被动语态、常见从句、条件句基础、简单非谓语 |
| B2 | 复杂句稳定性、让步/对比/因果结构、非谓语、名词性从句、段落衔接 |
| C1 | 名词化、强调结构、语体控制、高级衔接、复杂观点表达 |
| C2 | 高精度表达、细微语义控制、复杂文本风格和修辞灵活性 |

## 学习规划如何结合 CEFR

学习规划不应只说“多背单词、多练作文”。CEFR 可以把计划写成“从当前等级到目标等级”的差距路径。

### 规划模板

```text
当前：Writing B1+
目标：Writing B2

差距：
1. 能写连贯短文，但观点展开不够充分。
2. 能使用部分复杂句，但错误影响自然度。
3. 词汇够用，但正式表达和准确搭配不足。

训练路径：
第 1 周：句子准确性和连接表达
第 2 周：段落展开和例证
第 3 周：正式表达和观点支撑
第 4 周：限时写作与复盘
```

## RAG 拆分方案

CEFR 标准本体进数据库；教学解释和能力差距进 RAG。

### 不建议做全文 RAG

原因：

- Companion Volume 很长，全文检索容易召回噪声。
- 项目只需要英语学习产品相关内容，不需要手语、政策背景、完整研究说明。
- 大段官方文本直接入库存在版权和产品可控性问题。

### 推荐 RAG collection

| Collection | 内容 | 用途 |
| --- | --- | --- |
| `cefr_level_guidance` | A1-C2 的项目化中文解释 | 能力图、学习规划 |
| `cefr_writing_guidance` | 写作等级表现、写作评估维度、升级差距 | 写作评分解释 |
| `cefr_vocab_guidance` | 词汇范围、词汇控制、主动/被动使用建议 | Vocab Agent、Polish Agent |
| `cefr_grammar_guidance` | 语法准确度、复杂句控制、错误影响 | Grammar Agent、Scoring Agent |
| `cefr_learning_gap_guidance` | A2->B1、B1->B2、B2->C1 的差距 | Learning Planner Agent |

## 第一版建议

第一版只做：

1. 用户能力图：Overall / Reading / Writing / Listening / Spoken Interaction / Spoken Production。
2. 写作评分结果增加 `estimated_writing_cefr`。
3. 写作六维雷达继续保留，用于解释 CEFR 写作等级。
4. 单词书加 `cefr_level` 字段。
5. 建 `cefr_level_guidance` 和 `cefr_writing_guidance` 两个 RAG collection。

后续再做：

- 口语和听力模块。
- Mediation 能力。
- CEFR 自评问卷。
- 更细的 `A2+ / B1+ / B2+`。
