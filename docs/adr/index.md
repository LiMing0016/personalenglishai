# 架构决策记录

ADR 用来记录会长期影响项目方向的重要技术决策。

适合写 ADR 的场景包括：

- 引入或替换关键依赖。
- 改变部署拓扑。
- 改变持久化数据模型。
- 改变 AI 工作流或 Prompt 架构。
- 选择项目级文档、测试或发布流程。
