# Explanation Patterns

用这些模式组织语法讲解，避免回答过长。

## 单一语法点

结构：
1. 这个结构是什么。
2. 在当前句子里起什么作用。
3. 使用规则。
4. 常见错误。
5. 一个原创例句。

## 区别辨析

结构：
1. A 和 B 的核心区别。
2. 分别适合什么场景。
3. 当前句子应该用哪个。
4. 一个对比例句。

## 从句或长句结构

结构：
1. 先切分主干。
2. 标出从句或修饰成分。
3. 解释它修饰什么、表达什么关系。
4. 给出自然中文理解。

## 迁移提醒

优先说明：
- 这个结构适合写观点、原因、让步、对比、结果还是举例。
- 学生以后在什么作文场景可以复用。
- 当前学段是否需要掌握完整形式，还是先掌握基础用法。
