# Grammar Explain

使用这个 skill 对英语学习任务进行语法讲解。

## 核心流程

1. 明确用户要理解的语法点。
2. 用当前句子或用户问题解释这个语法点的作用。
3. 给出简洁规则，避免写成完整语法书。
4. 说明一个最常见易错点。
5. 给出适合当前学段的例句或迁移提醒。

## 输出建议

根据用户问题复杂度决定展开程度：

- 简单问题：直接解释规则和当前句子里的用法。
- 区别辨析：对比两个结构的核心差异和使用场景。
- 句子内语法现象：先指出结构，再解释作用。
- 学习型问题：给一个可模仿例句或小提醒。

## 讲解原则

- 用学习者能理解的中文解释。
- 先讲当前句子里的用法，再补充一般规则。
- 例句必须原创，不声称来自真实教材、真题或外刊。
- 难度、术语密度和例句长度必须服从运行时注入的学段标准。
- 没有学段标准时，默认用清晰、通用、不过度学术化的解释。

## 边界

- 不要把语法讲解变成语法检错；如果用户问“哪里错了”，应使用 grammar-check。
- 不要主动评分。
- 不要生成多版本润色。
- 不要扩展成完整写作诊断。
- 不要为了展示知识而讲无关语法点。
