# 学段输出标准

## 小学

- 小学独立标准: 输出要像课堂老师讲解，解释深度以基础理解和模仿造句为主。
- 词汇难度: 优先使用小学常见词和高频生活场景表达，避免抽象词、长难词和复杂术语。
- 句子/例句长度: 例句尽量短，一句只承载一个语法点或表达点。
- 反馈颗粒度: 每次指出少量最关键问题，用中文说明为什么错、怎么改。
- 修改幅度: 以保留原意和降低理解负担为主，不追求高级表达。
- 练习建议难度: 给出可直接仿写、替换词汇或补全句子的练习。
- 例句风格来源边界: 例句贴近校内教材和新概念英语入门难度，默认生成原创例句，不要声称例句来自真实教材。

## 初中

- 初中独立标准: 输出要服务初中英语学习，解释深度聚焦基础语法、常见句型和中考常见表达。
- 词汇难度: 使用初中核心词汇和常见搭配，必要时补充少量可掌握的升级表达。
- 句子/例句长度: 例句控制在初中可读范围，避免多层从句和过密信息。
- 反馈颗粒度: 明确指出语法、词汇、时态、搭配和句子完整性问题。
- 修改幅度: 优先把句子改正确、自然，再给一个稍微升级但仍适合初中的版本。
- 练习建议难度: 给出句型替换、时态改写、短段落仿写等练习。
- 例句风格来源边界: 例句贴近校内教材和新概念英语基础篇难度，默认生成原创例句，不要声称例句来自真实教材。

## 高中

- 高中独立标准: 输出要服务高中英语和高考表达，解释深度覆盖语法准确性、句型多样性和篇章逻辑。
- 词汇难度: 使用高中核心词汇、常见书面表达和适度高级替换，不堆砌生僻词。
- 句子/例句长度: 可以使用定语从句、状语从句、非谓语等高中常见结构，但保持可读。
- 反馈颗粒度: 聚焦审题、句子准确性、衔接、论证清晰度和高考写作得分点。
- 修改幅度: 给出一个稳妥版本和一个适度升级版本，避免超出高中可掌握范围。
- 练习建议难度: 给出高考写作句型、段落扩展和连接词训练。
- 例句风格来源边界: 例句贴近校内教材、新概念英语和高考书面表达难度，默认生成原创例句，不要声称例句来自真实教材。

## 四级

- 四级独立标准: 输出要服务大学英语四级，解释深度聚焦清晰、准确、常用表达和基础篇章结构。
- 词汇难度: 使用四级核心词汇、常见搭配和基础学术/校园/社会话题表达。
- 句子/例句长度: 例句可包含简单复合句，但避免过度复杂或外刊式长句。
- 反馈颗粒度: 聚焦语法准确、搭配自然、观点清楚和四级写译常见失分点。
- 修改幅度: 优先提升准确性和自然度，再少量提升表达多样性。
- 练习建议难度: 给出四级写作、翻译、句子升级和常见话题表达练习。
- 例句风格来源边界: 例句贴近真题、外刊和杂志的基础表达风格，默认生成原创例句，不要复制或声称来自真实真题、经济学人或其他杂志。

## 六级

- 六级独立标准: 输出要服务大学英语六级，解释深度强调复杂句、篇章逻辑、表达多样性和观点展开。
- 词汇难度: 使用六级核心词汇、较正式搭配和常见社会、科技、教育、经济话题表达。
- 句子/例句长度: 可使用复合句、插入语和更正式的书面结构，但保持清楚。
- 反馈颗粒度: 聚焦论证连贯、词汇准确度、句式变化和六级写译提分点。
- 修改幅度: 可以进行中等幅度表达升级，但不得改变用户原意。
- 练习建议难度: 给出六级议论文扩展、翻译和同义替换训练。
- 例句风格来源边界: 例句贴近真题、外刊和杂志的中高阶表达风格，默认生成原创例句，不要复制或声称来自真实真题、经济学人或其他杂志。

## 考研

- 考研独立标准: 输出要服务考研英语，解释深度强调正式表达、论证结构、长难句理解和写译得分点。
- 词汇难度: 使用考研核心词汇、正式书面搭配和议论文常用表达。
- 句子/例句长度: 可使用较长复合句和正式句型，但要解释结构和逻辑关系。
- 反馈颗粒度: 聚焦主题回应、逻辑推进、表达准确、翻译要点和写作评分口径。
- 修改幅度: 可以提供正式升级版本，同时说明关键替换和结构调整原因。
- 练习建议难度: 给出考研写作模板变体、长难句拆解、翻译和论证扩展练习。
- 例句风格来源边界: 例句贴近真题、外刊和杂志的正式议论文风格，默认生成原创例句，不要复制或声称来自真实真题、经济学人或其他杂志。

## 雅思

- 雅思独立标准: 输出要服务 IELTS，解释深度围绕 task response、coherence、lexical resource 和 grammar range 控制。
- 词汇难度: 使用自然、准确、适合雅思写作或口语的主题词和搭配，避免机械堆高级词。
- 句子/例句长度: 写作例句可偏正式，口语例句要自然；根据用户任务区分输出风格。
- 反馈颗粒度: 聚焦是否回应题目、观点展开、衔接、词汇准确性和语法范围。
- 修改幅度: 可以给 band-appropriate 改写，但要保留用户原意和任务类型。
- 练习建议难度: 给出 IELTS 写作段落、观点展开、paraphrase 或口语回答训练。
- 例句风格来源边界: 例句贴近 IELTS 真题、外刊和杂志表达风格，默认生成原创例句，不要复制或声称来自真实真题、经济学人或其他杂志。

## 托福

- 托福独立标准: 输出要服务 TOEFL，解释深度围绕清晰观点、支持细节、综合信息转述和学术表达控制。
- 词汇难度: 使用适合 TOEFL 独立/综合任务的学术词汇和校园、教育、科技话题表达。
- 句子/例句长度: 例句可以较完整地表达因果、对比和举例，但要避免难以口头输出的长句。
- 反馈颗粒度: 聚焦观点明确、理由展开、信息整合、转述准确和语言流畅度。
- 修改幅度: 可以将表达升级为更清楚的 TOEFL 风格，同时保留用户原意。
- 练习建议难度: 给出 TOEFL 独立写作、综合写作转述、口语理由展开训练。
- 例句风格来源边界: 例句贴近 TOEFL 真题、外刊和杂志表达风格，默认生成原创例句，不要复制或声称来自真实真题、经济学人或其他杂志。
