# PDF 原文渲染与精读文本双视图题目

## 背景

AI 精读工作台不能只把 PDF 拆成文本段落。很多一手资料包含图片、表格、图注、版式和页码，用户需要像 Acrobat 一样看到 PDF 原貌，同时还能使用右侧 Agent 做翻译、解释、笔记和学习资产沉淀。

本题目标是实现第一版 PDF 学习画布能力：

```text
上传 PDF
→ 后端解析出精读文本
→ 前端保留当前会话 PDF 预览地址
→ 工作台进入 IDE 式三栏布局
→ 左侧展示 PDF 页码 / 大纲导航
→ 中间默认进入“PDF 学习画布”
→ 画布保留 PDF 原貌，并叠加可复制文本层和批注层
→ 右侧 Agent 优先围绕当前选区工作，没有选区时围绕当前页/当前段落工作
→ 右侧保存当前页学习笔记和学习资产
```

第一版不要求完整复刻 Acrobat，也不要求把批注写回 PDF 文件。先解决“PDF 原貌能看、文本能复制、左侧能定位、右侧能围绕当前页做 Agent 分析和笔记”的问题。

---

## 题目 1：工作台支持 PDF 原文视图

### A 小题：保留 PDF 当前会话预览地址

#### 题目 Prompt

请在前端翻译 Hub 上传 PDF 后，为当前会话创建 PDF 预览地址，并随工作台草稿一起传入 AI 精读工作台。

要求：

1. 仅 PDF 文件创建预览地址。
2. 可以使用 `URL.createObjectURL(file)` 生成当前会话预览地址。
3. 草稿结构中新增 `pdfPreviewUrl` 字段。
4. 刷新页面后该地址可能失效，第一版需要在 UI 中轻量提示。
5. TXT / MD / DOCX 不应出现 PDF 预览入口，但可以继续使用精读文本视图。

#### 难度

中等

#### 验收标准

- 上传 PDF 后，工作台草稿包含 `pdfPreviewUrl`。
- 上传非 PDF 文件时，不生成 `pdfPreviewUrl`。
- 刷新后如果没有可用 PDF 预览地址，页面有兜底提示。
- 不影响现有 PDF 文本解析和工作台进入流程。
- 有前端测试覆盖 PDF 预览字段和非 PDF 行为。

---

### B 小题：实现“PDF 学习画布 / 精读文本”双视图

#### 题目 Prompt

请在 AI 精读工作台中间主工作区增加视图切换：

```text
[PDF 学习画布] [精读文本]
```

要求：

1. PDF 文档默认展示“PDF 学习画布”，精读文本作为辅助视图。
2. PDF 学习画布使用 `pdfjs-dist` 渲染 PDF 页面，而不是只使用浏览器原生 `object` / `iframe`。
3. 画布必须包含：
   - `canvas layer`：PDF 原貌渲染。
   - `text layer`：可复制文本层。
   - `annotation layer`：高亮和选区 Agent 入口。
4. 如果当前会话 PDF 地址失效，仍展示后端解析/OCR 得到的文本层，允许复制、笔记和 Agent 提问。
5. 右侧 Agent 不因视图切换而丢失上下文；存在选区时使用当前选区，否则使用当前页/当前段落。
6. 非 PDF 文件可以继续使用精读文本视图。

#### 难度

中等

#### 验收标准

- 工作台左侧能在 PDF 学习画布和精读文本之间切换。
- PDF 学习画布可以展示 PDF 文件原貌。
- PDF 学习画布包含可复制文本层、高亮选区入口和问 Agent 入口。
- 没有预览地址时展示兜底文本层，不阻断复制、笔记和 Agent 提问。
- Agent 当前上下文优先来自当前选区。
- 有前端测试覆盖视图切换相关 UI 文案。

## 题目 2：为 Acrobat 式精读能力建立前端结构

### A 小题：实现 PDF 页面和缩放状态

#### 题目 Prompt

请为 PDF 学习画布实现基础状态：

- 当前页码 `pdfPage`
- 缩放比例 `pdfZoom`
- PDF 加载失败状态
- 当前选区文本 `selectedPdfText`
- 目标跳转页码 `targetPdfPage`

要求提供上一页、下一页、缩放按钮，并把当前选区同步给工作台右侧 Agent。左侧大纲点击页码或段落时，中间 PDF 画布需要跳转到对应页。

#### 难度

中等

#### 验收标准

- 代码中存在清晰的 PDF 预览状态。
- 翻页和缩放不会破坏右侧 Agent 上下文。
- 当前选区能进入右侧 Agent 的上下文展示。
- 左侧大纲能驱动中间 PDF 跳页，中间翻页也能同步当前页状态。
- `pdfjs-dist` 只进入翻译工作台相关懒加载 chunk，不影响写作页主链路。

---

### B 小题：实现可扩展批注层

#### 题目 Prompt

请在 PDF 学习画布中实现可扩展批注层。

后续目标：

```text
canvas layer：PDF 页面原貌
text layer：PDF 内置文本 / OCR 文本
annotation layer：高亮选区 / 页边笔记 / 后续 bbox 锚点
```

第一版需要保证：

1. `DocumentBlock` / 后续 `DocumentNode` 可以保留 pageNumber。
2. 前端 PDF 学习画布区域有独立组件，内部明确分层。
3. 用户选中文本后可以高亮、复制、问 Agent。
4. 用户可以在右侧 Agent Console 写当前页学习笔记，笔记按文档和页码保存。

#### 难度

中等

#### 验收标准

- PDF 学习画布容器独立。
- 精读文本视图和 PDF 学习画布状态分离。
- 后续可在 annotation layer 上叠加 bbox 高亮层。
- 当前页笔记不会修改原 PDF 文件。

## 题目 3：实现 IDE 式三栏精读工作台

### A 小题：左侧 PDF 大纲与页码导航

#### 题目 Prompt

请把 AI 精读工作台改成类似 VS Code / IDE 的三栏结构：

```text
左侧：PDF 大纲 / 页码导航
中间：PDF 学习画布 / 精读文本
右侧：翻译 Agent / 学习笔记
```

左侧需要根据 `DocumentBlock.pageNumber` 聚合出页码组。每个页码组下展示该页的标题、段落或题目块。点击页码或块时：

1. 中间 PDF 学习画布跳转到对应页。
2. 当前 `activeBlockId` 更新。
3. 右侧 Agent 当前上下文同步到对应页 / 段落。
4. 当前选区清空，避免旧选区污染新上下文。

#### 难度

中等

#### 验收标准

- 页面存在清晰的左侧大纲栏、中间画布栏、右侧 Agent 栏。
- 左侧大纲按页码聚合 `DocumentBlock`。
- 点击页码能跳转中间 PDF 页。
- 点击段落能更新当前段落和 Agent 上下文。
- 有测试覆盖 `PDF 大纲`、`PAGE NAVIGATOR`、`workspace-outline-panel` 等关键结构。

---

### B 小题：右侧 Agent Console 承载当前页笔记

#### 题目 Prompt

请把当前页学习笔记放到右侧 Agent Console，而不是放在 PDF 中间画布旁边。

要求：

1. 右侧展示当前上下文、推荐译文、快捷操作、学习资产候选、学习笔记和多轮问答输入。
2. 学习笔记按 `documentId + pageNumber` 保存。
3. 切换 PDF 页码或左侧大纲时，笔记输入框切换到当前页对应内容。
4. 保存笔记不修改原 PDF 文件。
5. 后续 Agent 可以读取当前页笔记作为上下文。

#### 难度

中等

#### 验收标准

- 右侧存在 `学习笔记` 区域。
- 切换当前页后，笔记绑定到对应页。
- 笔记持久化使用文档级 key，避免不同文档互相污染。
- Agent 当前上下文优先显示选区，没有选区时显示当前页 / 当前段落。
- 有测试覆盖 `学习笔记` 和三栏工作台结构。

---

## 推荐实施顺序

```text
1. 草稿模型新增 pdfPreviewUrl
2. 上传 PDF 后生成 object URL
3. 引入 `pdfjs-dist`
4. 新增 `PdfLearningCanvas` 独立组件
5. 工作台改成左侧大纲 / 中间画布 / 右侧 Agent 三栏
6. 工作台默认打开 PDF 学习画布
7. 画布内实现 canvas layer、text layer、annotation layer
8. 左侧大纲与中间 PDF 页码双向同步
9. 右侧 Agent 接入当前选区上下文和当前页笔记
10. 精读文本保留为辅助视图
```

## 总体验收标准

- 用户上传 PDF 后，工作台能看到解析后的精读文本。
- 用户可以在 PDF 学习画布中查看 PDF 原文原貌。
- PDF 中的图片、表格和版式由 pdf.js canvas layer 保留。
- 左侧大纲可以按页定位 PDF 内容。
- 用户可以复制文本层内容。
- 用户可以围绕当前选区问 Agent。
- 用户可以在右侧给当前页写学习笔记，并在批注层看到高亮选区。
- 右侧 Agent 不受视图切换影响。
- 当前实现为后续 bbox 高亮、框选问答和批注导出能力预留空间。
