# 通用资料学习资产类型体系完整实现题目

## 背景

AI 精读工作台未来不应只服务英语翻译材料，而应升级为“资料学习 IDE”：用户上传英语材料、专业书籍、教材、论文、考试资料、行业报告或工作文档后，系统能够解析资料、保留来源、让 Agent 围绕资料回答问题，并把学习过程沉淀为可复习、可检索、可回跳的长期学习资产。

学习资产类型需要从英语学习资产扩展为完整体系：

```text
英语类：词汇 / 短语 / 句型 / 语法
知识类：概念 / 术语 / 公式 / 定理
理解类：论点 / 案例 / 方法 / 结论
训练类：例题 / 错题 / 复习卡 / 笔记
```

本题单是完整目标拆解，不是当前 MVP 范围。题目覆盖前端、后端、全栈、Agent、数据持久化、复习系统、搜索、权限、评估与运维。

参考文件：

- `docs/product/AI精读工作台完整产品方案.md`
- `tasks/6.9/统一文档解析管线与沉浸式翻译IDE题目.md`
- `web/src/pages/app/TranslationWorkspacePage.vue`
- `web/src/pages/app/translationWorkspaceData.ts`
- `web/src/pages/app/translationHubData.ts`
- `backend/src/main/java/com/personalenglishai/backend/service/translation`
- `backend/src/main/java/com/personalenglishai/backend/controller/translation`

总体原则：

1. 学习资产不是 UI 标签，而是贯穿文档、Agent、复习、搜索和统计的数据模型。
2. 所有资产必须保留来源：documentId、blockId、pageNumber、sourceText、chunkId。
3. Agent 生成资产必须结构化，并经过用户确认。
4. 不同资料模式只展示相关资产类型，不一次性暴露全部类型。
5. 后端接口必须统一，不为每个资产类型单独建一套接口。
6. 前端、后端和 Agent 协议要能独立测试。

## 题目 1：学习资产类型系统与兼容迁移

题目类型：frontend + backend contract

难度：偏难

### A 小题：定义统一资产类型注册表

#### Prompt

请实现统一学习资产类型注册表，覆盖英语类、知识类、理解类、训练类资产。注册表需包含 type、group、中文名、适用资料模式、默认图标、默认颜色、是否可复习。

#### 难度

中等偏难

#### 验收标准

- 16 种资产类型由统一注册表管理。
- 前端和后端使用同一组 type 字符串。
- 新增类型不需要改多个组件硬编码。
- `sentence` 等旧类型能兼容到 `sentence_pattern`。
- 有测试覆盖类型分组和兼容迁移。

### B 小题：建立资产类型后端枚举与校验

#### Prompt

请在后端建立 LearningAssetType 枚举和校验逻辑，所有保存、更新、查询接口都必须校验资产类型合法性。

#### 难度

中等

#### 验收标准

- 非法 type 返回 400。
- 后端不会保存未知资产类型。
- 枚举包含 group 和 reviewable 属性。
- DTO、Service、Controller 使用同一套类型。
- 有单元测试覆盖合法和非法 type。

#### Prompt

困难

## 题目 4：资产去重与质量校验

难度：困难

### A 小题：实现规则去重

#### Prompt

请实现学习资产规则去重。同一用户、同一文档、同一 block、同一 type、近似标题的资产不应重复创建。

#### 难度

偏难

- 同一 block 重复保存同一概念会被识别。
- 大小写、空格、标点差异不会绕过去重。

- 返回重复资产 id。
- 有测试覆盖边界情况。

### B 小题：实现资产质量校验

#### Prompt

请实现资产保存前质量校验，拦截空标题、空内容、过短内容、明显乱码、缺少来源的 Agent 资产。

#### 难度

中等偏难

#### 验收标准

- 空资产不会入库。
- Agent 生成资产缺少 sourceText 时被拒绝或降级为草稿错误。
- 乱码资产被标记为 low quality。
- 错误信息可展示给前端。
- 有测试覆盖低质量资产。

请确保学习资产接口按当前登录用户隔离，用户只能访问自己的资产和自己有权限的文档资产。

#### 难度

困难

#### 验收标准

- 用户 A 不能读取用户 B 的资产。
- documentId 查询会校验文档归属。
- 更新和删除也校验权限。
- 未登录请求返回认证错误。
- 有安全测试。

### B 小题：实现分享场景权限策略

#### Prompt

请设计文档分享场景下的资产权限策略，区分只读资产、可复制资产和个人私有资产。

#### 难度

困难

#### 验收标准

- 分享文档不会暴露作者私有笔记。
- 被分享用户可生成自己的资产。
- 可复制资产能复制到个人资产库。
- 权限策略有文档说明。
- API 不泄露私有 metadata。

## 题目 18：资产效果评估与测试集

题目类型：test + evaluation

难度：困难

### A 小题：建立资产抽取评估集

#### Prompt

请建立学习资产抽取评估集，覆盖英语材料、考研资料、专业书、论文、工作文档，每类至少 3 个样本。

#### 难度

偏难

#### 验收标准

- 样本包含原文、期望资产类型、期望来源。
- 覆盖至少 5 种资料模式。
- 覆盖至少 10 种资产类型。

#### Prompt

请实现资产抽取质量评估脚本，统计类型准确率、来源命中率、重复率、低质量率和用户确认率。

#### 难度

困难

#### 验收标准

- 输出可读评估报告。
- 能统计 type accuracy。
- 能统计 source grounding rate。
- 能统计 duplicate rate。
- 指标可用于比较不同 Prompt 或模型。

请为资产生成、确认、编辑、删除、回跳、复习、导出增加埋点事件。

偏难

- Agent run 可看到资产生成动作。
- 可追踪失败原因。
- 可统计生成到确认的转化。
- 不泄露用户完整私有文档。
- 有调试页展示字段。

## 题目 20：完整端到端验收

题目类型：fullstack acceptance

难度：困难

### A 小题：实现英语资料完整闭环验收

#### Prompt

请完成英语资料端到端验收：上传英文 PDF，选择英语精读，Agent 提取词汇、短语、句型、语法，用户确认资产，进入复习队列，并能从资产回跳原文。

#### 难度

困难

#### 验收标准

- 上传和解析成功。
- 工作台只展示英语相关资产类型。
- Agent 生成结构化草稿。
- 用户确认后资产入库。
- Hub 和复习队列都能看到资产。
- 来源回跳准确。

### B 小题：实现专业资料完整闭环验收

#### Prompt

请完成专业资料端到端验收：上传专业书或论文，选择专业/论文模式，Agent 提取概念、术语、方法、论点、结论，用户确认后可搜索、复习和回跳来源。

#### 难度

困难

#### 验收标准

- 专业资料不默认展示英语语言点。
- Agent 生成知识类和理解类资产。
- 搜索能找到概念或术语。
- 复习队列能出现概念/术语。
- 点击资产能回到原文位置。
- 全链路有测试或人工验收记录。
