# 全局左侧导航栏收起 / 展开 Trae 实现题目

## 背景

当前应用左侧有一条固定 `AppRail`，包含 PEAI logo、写作、学习助手、阅读、听力、口语、新建对话、搜索、历史和个人中心入口。

在写作、Dashboard、学习助手等页面中，这条左侧栏一直占用宽度，并且会显示一条竖向边框。用户希望它可以全局收起：

- 收起后不再保留整条左侧边框。
- 页面内容可以占满更多横向空间。
- 只保留一个 PEAI logo 作为展开入口。
- 点击 PEAI logo 可以展开或收起左侧栏。

设计原则：

- PEAI logo 只负责控制全局左侧栏展开 / 收起。
- 学习助手入口仍然是左侧栏里的学习助手图标。
- 不让 PEAI logo 同时承担“打开学习助手抽屉”的职责。
- 收起状态是用户偏好，应跨页面、刷新后保持。
- 不改写作编辑器、评分、语法、润色等核心链路。

涉及文件优先集中在：

- `web/src/layouts/AppLayout.vue`
- `web/src/components/AppRail.vue`
- `web/tests/appRailChrome.test.ts`

---

## 题目 1：在 AppLayout 增加全局左侧栏收起状态

### Prompt

给应用主布局增加全局左侧栏收起 / 展开状态。

要求：

1. 在 `AppLayout.vue` 中维护 `railCollapsed` 状态。
2. 使用 `localStorage` 持久化用户偏好，建议 key 为：
   - `peai:app-rail-collapsed`
3. 初始状态从 `localStorage` 读取。
4. 切换页面后保持当前收起状态。
5. 刷新页面后保持当前收起状态。
6. 给根节点增加状态 class，例如：
   - `app-layout--rail-collapsed`
   - `app-layout--rail-expanded`
7. 不要把这个状态绑定到某个具体路由，也不要只在写作页生效。

### 验收标准

- 任意 `/app/*` 页面都能读取同一个左侧栏收起状态。
- 刷新后状态不丢。
- 不影响已有 `immersive` 逻辑。
- 不影响 `app-layout--writing` 的暖色背景逻辑。
- 没有新增全局状态库。

---

## 题目 2：改造 AppRail 的收起与展开展示

### Prompt

改造 `AppRail.vue`，让它支持收起模式。

要求：

1. 新增 props：
   - `collapsed`
2. 新增事件：
   - `toggle-rail`
3. PEAI logo 点击时触发 `toggle-rail`。
4. PEAI logo 不再触发学习助手抽屉打开。
5. 展开状态：
   - 保持现有完整左侧栏。
   - 显示所有导航按钮、工具按钮和个人中心。
6. 收起状态：
   - 不显示导航按钮、工具按钮和个人中心。
   - 只显示一个 PEAI logo 按钮。
   - 不保留完整 64px 边栏。
7. 收起 / 展开需要有轻微过渡动画。

### 验收标准

- 点击 PEAI logo 可以在展开和收起之间切换。
- 收起后页面左侧没有整条竖向边框。
- 收起后主内容区域向左扩展。
- 展开后现有导航入口都能正常点击。
- PEAI logo 的 `title` / `aria-label` 能表达当前动作：展开导航 / 收起导航。

## 题目 3：处理学习助手页面职责分离

### Prompt

调整学习助手相关交互，确保 PEAI logo 只负责全局导航栏，不负责学习助手侧栏。

要求：

1. PEAI logo 点击只控制 `AppRail` 收起 / 展开。
2. 学习助手入口继续使用左侧栏里的“学习助手”图标。
3. 如果当前在 `/app/assistant`：
   - 点击 PEAI logo 不应该离开当前页面。
   - 点击 PEAI logo 不应该打开或关闭学习助手内部侧栏。
4. 学习助手页面内部自己的侧栏开关继续由学习助手页面内部逻辑管理。
5. 保留选中文本后“询问 AI 助手”的逻辑，不要破坏选择文本跳转助手页的能力。

### 验收标准

- 在 `/app/assistant` 页面点击 PEAI logo，只改变全局左侧栏状态。
- 不会触发路由跳转。
- 不会误调用 `openAssistantDrawer`。
- 原有“新建对话 / 搜索 / 历史对话”按钮在展开状态下仍然能打开学习助手。
- 选中文本询问 AI 助手功能仍然可用。

## 题目 4：补充布局样式与响应式细节

### Prompt

完善全局左侧栏收起后的布局样式。

要求：

1. 展开状态保持当前 `64px` 左侧栏宽度。
2. 收起状态建议采用浮动 logo：
   - `position: fixed`
   - 左上角留出安全边距
   - `z-index` 高于页面主体但低于弹窗
3. 收起状态下 `.app-main` 不再被左侧栏占宽。
4. 过渡动画要轻：
   - 宽度 / transform / opacity 约 `160ms-220ms`
5. 写作页面、Dashboard、学习助手页面、个人中心页面都不能出现明显横向抖动。
6. 移动端或窄屏下不要遮挡主要按钮。

### 验收标准

- 收起状态截图中只看到浮动 logo，不看到整条左侧栏。
- 展开状态截图与原页面结构一致。
- 切换时没有明显内容跳动。
- 写作编辑器顶部工具栏不被浮动 logo 遮挡。
- Dashboard 宽屏布局不会因为收起/展开发生内容溢出。

## 题目 5：补充前端测试与手工验收清单

### Prompt

为全局左侧栏收起 / 展开补充测试。

要求：

1. 更新或新增 `appRailChrome.test.ts`。
2. 测试至少覆盖：
   - AppRail 默认展开。
   - 源码存在 `peai:app-rail-collapsed` 持久化 key。
   - PEAI logo 触发 `toggle-rail`，不触发学习助手抽屉。
   - 收起状态 class 存在。
   - 收起状态下 AppRail 只保留 logo。
3. 保留现有导航图标测试，不要删除已有断言。
4. 构建必须通过。

### 验收标准

自动验证：

```bash
node tests\appRailChrome.test.ts
npm run build
```

手工验收：

1. 进入 `/app/writing`，点击 PEAI logo，左侧栏收起。
2. 刷新页面，仍保持收起。
3. 再点 PEAI logo，左侧栏展开。
4. 进入 `/app/assistant`，点击 PEAI logo，不跳转、不打开或关闭助手内部侧栏，只控制全局左侧栏。
5. 展开左侧栏后，写作、学习助手、阅读、听力、口语、个人中心入口都能正常跳转。

## 最终交付标准

- 左侧导航栏全局可收起 / 展开。
- 收起状态只保留 PEAI logo。
- 收起状态跨页面和刷新保持。
- PEAI logo 职责单一：只控制全局导航栏。
- 学习助手入口和学习助手内部侧栏逻辑不被混用。
- 不破坏写作编辑器主链路。
- 测试和构建通过。
