# 单词收藏、查询次数与我的收藏页真实数据 Trae 题目

## 背景

当前 `/app/vocabulary` 已经完成单词搜索页和牛津词典详情展示，用户可以搜索单词并查看本地词典或 Oxford 返回的释义、音标、发音和例句。

下一步需要把“收藏单词”和“查询次数”从前端临时状态升级为用户维度的真实数据，并让“我的收藏 / 生词本”页面展示用户实际收藏过的单词。这样用户可以在搜索页收藏单词，也可以在收藏页集中查看、搜索、取消收藏，并跳回完整词典详情。

## 总体要求

1. 收藏状态必须按用户隔离，不能写入全局 `dictionary_entry`。
2. 每次用户成功查询单词后，应累计该用户对该单词的查询次数。
3. 单词详情页需要展示：
   - 是否已收藏
   - 当前用户查询该单词的次数
4. 单词详情页星标按钮需要调用后端接口更新收藏状态。
5. “我的收藏 / 生词本”页不能继续使用 mock 收藏数据，需要调用后端真实接口。
6. 收藏列表需要支持：
   - 搜索收藏单词
   - 分页
   - 取消收藏
   - 查看完整词典详情
7. 收藏列表的释义预览从本地 `dictionary_*` 表补充，不复制完整词典正文到用户状态表。
8. 保持现有单词页视觉风格，避免新增独立页面或新路由。
9. 后端接口必须通过鉴权后的 `userId` 获取当前用户数据，未登录时返回 401。

## 非目标

- 不实现完整复习队列。
- 不实现分组管理。
- 不实现批量导出。
- 不实现学习状态流转，例如新学、学习中、已掌握。
- 不实现跨设备离线缓存。
- 不把牛津原始 HTML 或完整词典正文复制到用户收藏表。

## 题目 1：新增用户单词状态表

### 题目 Prompt

请在后端新增用户维度的单词状态存储，用于记录用户对某个单词的收藏状态、查询次数、首次查询时间、最近查询时间和收藏时间。公共词典内容继续保存在 `dictionary_*` 表中，用户行为写入新表。

### 实现要求

1. 新增表 `user_dictionary_word_state`。
2. 唯一键使用 `user_id + normalized_word`。
3. 字段至少包含：
   - `id`
   - `user_id`
   - `word`
   - `normalized_word`
   - `language`
   - `source`
   - `favorite`
   - `lookup_count`
   - `first_lookup_at`
   - `last_lookup_at`
   - `favorited_at`
   - `created_at`
   - `updated_at`
4. 增加收藏查询和最近查询相关索引。
5. 同步更新 `schema.sql` 和独立迁移 SQL。
6. 新增实体、Mapper interface 和 MyBatis XML。

### 验收标准

- 表结构可重复执行创建。
- `favorite` 默认值为 `0`。
- `lookup_count` 默认值为 `0`。
- 同一用户同一标准化单词只能有一条状态记录。
- 数据库结构测试覆盖该表的关键字段和索引。

## 题目 2：查询单词时累计查询次数并返回状态

### 题目 Prompt（完成）

请改造 `GET /api/dictionary/lookup`，当用户已登录且查询成功时，自动累计当前用户对该单词的查询次数，并把该单词的收藏状态和查询次数附加到词典查询响应中。

### 实现要求

1. `DictionaryLookupResponse` 增加：
   - `favorite`
   - `lookupCount`
2. `DictionaryController.lookup` 读取可选 `userId`。
3. 用户未登录时仍可查词，但不写入用户状态。
4. 用户已登录且查词成功时：
   - `lookup_count + 1`
   - 更新 `last_lookup_at`
   - 首次查询时写入 `first_lookup_at`
5. 查词失败时不累计查询次数。
6. 状态更新失败时不应影响词典查询主流程，可以记录 warn 日志。

### 验收标准

- 登录用户查询成功后响应包含 `favorite` 和 `lookupCount`。
- 未登录用户查询仍然可用。
- 查询失败不新增用户状态。
- Controller 单测覆盖查询响应和异常映射。

## 题目 3：实现收藏和取消收藏接口

### 题目 Prompt

请新增收藏状态更新接口，允许用户在单词详情页点击星标收藏或取消收藏。

### 接口设计

```http
POST /api/dictionary/words/{word}/favorite
```

请求体：

```json
{
  "favorite": true,
  "language": "en-gb"
}
```

响应：

```json
{
  "word": "innovative",
  "language": "en-gb",
  "favorite": true,
  "lookupCount": 3
}
```

### 实现要求

1. 未登录用户返回 401。
2. `word` 为空时返回 400。
3. 收藏时写入或更新 `favorite = 1`、`favorited_at`。
4. 取消收藏时写入 `favorite = 0`、清空 `favorited_at`。
5. 如果该单词此前未被查询过，允许直接收藏，`source` 可标记为 `manual`。

### 验收标准

- 收藏和取消收藏都能返回最新状态。
- 不重复插入同一用户同一单词。
- 单测覆盖成功收藏和未登录失败。

## 题目 4：实现我的收藏分页列表接口

### 题目 Prompt（完成）

请新增收藏列表接口，供“我的收藏 / 生词本”页面读取真实收藏数据。

### 接口设计

```http
GET /api/dictionary/favorites?keyword=&page=1&size=10
```

响应数据：

```json
{
  "items": [
    {
      "word": "spark",
      "language": "en-gb",
      "source": "local",
      "favorite": true,
      "lookupCount": 5,
      "favoritedAt": "2026-05-28T16:41:00",
      "lastLookupAt": "2026-05-28T16:42:00",
      "phonetic": "spɑːk",
      "partOfSpeech": "noun",
      "meaning": "a very small burning piece of material；火花"
    }
  ],
  "total": 1,
  "page": 1,
  "size": 10
}
```

### 实现要求

1. 未登录用户返回 401。
2. `keyword` 支持按 `word` 和 `normalized_word` 模糊查询。
3. `page` 最小为 1。
4. `size` 限制在合理范围，例如 1 到 50。
5. 收藏列表按 `favorited_at DESC, updated_at DESC, id DESC` 排序。
6. 释义预览从 `dictionary_entry`、`dictionary_pronunciation`、`dictionary_sense` 获取。
7. 如果本地词典未匹配到释义，列表仍返回用户收藏记录，只是预览字段为空或展示兜底文案。

### 验收标准

- 收藏列表只返回当前用户收藏的单词。
- 搜索、分页和总数正确。
- 返回项包含音标、词性、释义预览、查询次数和收藏时间。
- Controller 单测覆盖列表接口。

## 风险点

1. 如果生产数据库没有执行迁移 SQL，收藏接口会报表不存在。
2. 如果 `userId` 没有被鉴权拦截器注入，收藏接口会返回 401。
3. 收藏列表释义预览依赖本地词典入库，未入库的词只能展示基础收藏记录。
4. 搜索页和收藏页共享收藏状态时，需要同步更新本地前端状态，避免星标状态滞后。
5. 全量测试可能输出已有 OpenAI、JSON 包重复、chunk size warning，需要区分是否为本需求引入。

## 完成定义

用户可以完成以下完整链路：

1. 登录后进入 `/app/vocabulary`。
2. 搜索一个单词。
3. 单词详情展示查询次数和收藏状态。
4. 点击星标收藏。
5. 切换到“我的收藏 / 生词本”。
6. 在收藏列表中看到该单词、音标、释义预览、查询次数和收藏时间。
7. 在收藏列表中点击查看详细释义，回到搜索页展示完整词典详情。
8. 在收藏列表中取消收藏，该单词从列表移除。
