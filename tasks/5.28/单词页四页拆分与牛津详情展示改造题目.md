# 单词页四页拆分与牛津详情展示改造 Trae 题目

## 背景

当前用户侧 `/app/vocabulary` 单词页信息密度过高，把接口状态、学习统计、复习队列、单词列表和单词详情混在同一个视图里，页面不够像正式学习产品，也不利于用户完成“查词 -> 看释义 -> 加入复习”的主流程。

参考设计稿希望把单词学习拆成四个清晰页面：

- 搜索单词
- 背词模式
- 我的收藏
- 学习统计

其中“搜索单词”页面需要进一步调整布局：搜索框下面展示热门搜索和最近搜索，单词详情放在搜索区域正下方，搜索结果列表放在详情下方。单词详情应优先展示 `GET /api/dictionary/lookup` 返回的牛津/本地词典查询结果，而不是只展示本地 mock 学习词条。

## 总体要求

1. 用户侧页面不再展示“接口接入状态”“数据源验收标记”等研发验收信息。
2. `/app/vocabulary` 顶部导航拆成四个页面入口：搜索单词、背词模式、我的收藏、学习统计。
3. 搜索页保持真实词典查询能力，继续调用 `lookupDictionary()`。
4. 搜索后的单词详情必须位于搜索区域正下方，不放在右侧窄栏。
5. 热门搜索和最近搜索并排展示，最近搜索作为搜索辅助信息放在右侧。
6. 单词详情展示应贴近牛津词典风格，但整体视觉仍符合项目现有绿色、白底、卡片化学习产品风格。
7. 有词典查询结果时，详情内容以查询结果为准；没有查询结果时，才回退到本地学习词条。
8. 不新增前端依赖，不重做路由结构，不改生产登录和鉴权逻辑。
9. 保持页面响应式可用，移动端不出现内容重叠。

## 非目标

- 不实现真实收藏、复习、掌握状态入库。
- 不实现完整 Oxford 原站 HTML 还原。
- 不新增后端接口。
- 不处理 MDX/MDD 解析和词典全量入库。
- 不把设计预览图、截图或词典原始资源提交到源码目录。

## 题目 1：拆分单词页为四个学习视图

### 题目 Prompt

请改造 `web/src/views/VocabularyView.vue`，把当前混杂的单词学习页面拆成四个顶部导航视图：搜索单词、背词模式、我的收藏、学习统计。默认进入搜索单词视图，点击顶部导航可以在四个视图之间切换。不要新增路由，优先在当前单文件组件内完成。

### A 小题：搭建四页顶部导航与基础布局

#### 实现要求

1. 新增 `activeView` 状态，支持 `search / modes / collection / stats`。
2. 顶部保留品牌区域 `词启 Vocabulary`。
3. 顶部导航包含：
   - 搜索单词
   - 背词模式
   - 我的收藏
   - 学习统计
4. 当前激活页面需要有明确的绿色高亮状态。
5. 页面根容器使用新的学生端页面类名，例如 `vocabulary-shell`，不再使用旧的 `learning-shell`。

#### 难度

中等

#### 验收标准

- 进入 `/app/vocabulary` 默认显示搜索单词页。
- 四个导航按钮都能切换对应视图。
- 页面不再出现 `单词端数据源验收标记`。
- 页面源码不再依赖旧的 `apiStatusItems` 学生端展示。

### B 小题：实现背词模式、收藏和统计页静态展示

#### 实现要求

1. 背词模式页展示三种学习模式：
   - 智能复习
   - 新词学习
   - 拼写训练
2. 背词模式页右侧展示今日学习计划卡片。
3. 我的收藏页展示收藏筛选、搜索框、收藏单词表格和右侧单词预览。
4. 学习统计页展示 KPI 卡片、学习趋势、掌握情况分布、连续学习日历和里程碑。
5. 这些区域第一版可以使用本地静态数据，但不要伪装成已接正式 API。

#### 难度

中等

#### 验收标准

- 四个页面视觉结构与设计稿方向一致。
- 收藏页仍可点击词条切换右侧预览。
- 学习统计页在桌面宽度下信息分区清晰。
- 移动端布局能自动堆叠，不横向溢出。

## 题目 2：重排搜索页布局

### 题目 Prompt

请调整搜索单词页布局，使页面更接近设计稿：搜索框位于顶部，热门搜索和最近搜索位于搜索框下方，最近搜索在热门搜索旁边；单词详情位于这两个搜索辅助区块的正下方；搜索结果列表位于单词详情下方。

### A 小题：搜索辅助区块布局

#### 实现要求

1. 搜索标题区包含：
   - `Search`
   - `搜索单词`
   - `查询、学习、一步到位`
2. 搜索框支持输入单词、选择 `en-gb / en-us`、点击搜索。
3. 热门搜索使用横向 chip 按钮展示。
4. 最近搜索作为独立紧凑卡片展示在热门搜索右侧。
5. 点击热门搜索或最近搜索可以把词填入搜索框。

#### 难度

简单

#### 验收标准

- 最近搜索不再占据详情卡右侧区域。
- 热门搜索和最近搜索在桌面端并排展示。
- 小屏幕下两个区块上下堆叠。

### B 小题：搜索结果列表下移

#### 实现要求

1. 搜索结果列表放在详情卡片下方。
2. 结果列表保留单词、音标、词性、释义、收藏状态。
3. 点击结果行可以切换当前本地选中词。
4. 结果行高亮状态要清晰，但不要抢详情卡片的视觉优先级。

#### 难度

简单

#### 验收标准

- 搜索页视觉顺序为：搜索框 -> 热门/最近 -> 单词详情 -> 搜索结果。
- 搜索结果列表不会把单词详情挤到右侧。
- 结果列表在移动端不出现文字重叠。

## 题目 3：设计并实现牛津风格单词详情卡

### 题目 Prompt

请在搜索页中实现一个新的单词详情展示卡片，视觉上参考牛津词典的层级：词头、英美音标、来源、词性、释义、例句、常用搭配、学习补充信息。卡片要符合项目当前绿色学习产品风格，不要照搬牛津网页的原始样式。

### A 小题：新增 DictionaryDetail 展示组件

#### 实现要求

1. 可以在 `VocabularyView.vue` 内部定义 `DictionaryDetail`，不强制拆新文件。
2. 组件接收：
   - `result: DictionaryLookupResponse | null`
   - `word: LearningWord`
   - `sourceTitle`
   - `lastLookupAt`
3. 有 `result.entries` 时，释义和例句必须来自 `result.entries`。
4. 有 `result.phonetics` 时，英美音标优先来自 `result.phonetics`。
5. 没有 `result` 时，才使用本地 `word` 作为兜底展示。
6. 卡片顶部展示来源：
   - `source === local` 显示 `已安装本地词典`
   - `source === oxford` 显示 `Oxford Dictionaries`
   - 未知来源显示原始来源或 `词典查询`
7. 卡片提供学习动作：
   - 加入今日复习
   - 标记已掌握
   - 播放发音（有 audioUrl 时）

#### 难度

中等

#### 验收标准

- 搜索 `courage` 时，详情卡展示 `courage` 的查询结果，不混入 `innovative` 的本地释义。
- 查询结果的词性、释义、例句来自 `result.entries`。
- 查询结果的音标来自 `result.phonetics`。
- 没有查询结果时，页面仍能展示默认学习词条，避免空白。

### B 小题：长释义展开与学习补充信息

#### 实现要求

1. 多条释义默认只展示前几条，提供 `展开更多 / 收起`。
2. 例句以浅色块或引用块展示，英文和中文层级要清楚。
3. 常用搭配 / 习语作为独立区块展示。
4. 近义词、派生词、词根联想作为学习补充区块展示。
5. 如果当前查询词没有匹配本地学习词条，学习补充区块显示空状态说明，不混入其他单词数据。

#### 难度

中等

#### 验收标准

- 长释义可以展开和收起。
- 词典详情卡片在桌面端宽度充足，阅读不拥挤。
- `result.word !== word.word` 时，不展示错误的本地近义词、派生词或词根。
