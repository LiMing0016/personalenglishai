# 作文资产写作教练历史对话导出按钮 Trae 实现题目

## 背景

用户中心“作文资产”详情已经用于展示一篇归档作文的核心档案，包括作文正文、题目信息、评分记录、写作教练对话和 Markdown 档案。

当前需要进一步优化“写作教练对话”区域：这里不能替代作文核心档案，也不能只展示整份作文 Markdown。正确设计是：

- 作文资产详情继续保留作文核心数据。
- “Markdown 档案”仍然是整篇作文资产的完整档案。
- 在“写作教练对话”分区，为每段已关联的写作教练历史会话提供一个单独按钮。
- 用户点击按钮后下载该段写作教练历史对话的 `.md` 文件。
- 用户可以用 Typora、Obsidian、VS Code、Notion 等外部软件打开该 Markdown 文件。

注意：Web 页面不要尝试直接唤起用户本机任意软件。更稳定的方式是下载 Markdown 文件，由用户自行选择外部软件打开。

## 总体要求

1. 保留作文资产详情中的核心数据展示，不移除作文正文、题目信息、评分记录和整份 Markdown 档案。
2. 在“写作教练对话”分区增加历史对话导出按钮。
3. 每个已关联的写作教练会话对应一个导出按钮。
4. 导出的 Markdown 只包含该段写作教练历史对话，不混入整篇作文正文和评分记录。
5. 导出接口必须校验当前用户是作文 owner。
6. 导出接口必须校验该 `conversationId` 已经和当前作文关联。
7. 不修改生产登录逻辑。
8. 不通过 IP、User-Agent、浏览器特征、mock token 绕过鉴权。

## 非目标

- 不直接打开 Typora、Obsidian、VS Code、Notion 等本机软件。
- 不删除或替换整份作文 Markdown 档案。
- 不把未关联到当前作文的普通 assistant conversation 暴露出来。
- 不改写写作教练消息生成逻辑。
- 不改变作文归档、取消归档和资产刷新语义。

## 题 1：后端写作教练对话 Markdown 导出

### 发给 Trae 的 Prompt

请为作文资产新增单段写作教练历史对话 Markdown 导出能力。接口必须确认当前用户拥有该作文，并且请求的教练会话已经和该作文关联。

### 小题 A：服务层生成单段教练对话 Markdown

#### 题目 Prompt（完成）

请在后端作文资产服务中新增方法，用于导出某篇作文下某一段已关联写作教练会话的 Markdown。

要求：

1. 方法入参包含：
   - `tenantId`
   - `workspaceId`
   - `publicDocId`
   - `userId`
   - `conversationId`
2. 先校验当前用户是作文 owner。
3. 再校验 `conversationId` 已经通过 `writing_document_conversation_link` 关联到当前作文。
4. 如果作文不存在，返回现有 `DOC_NOT_FOUND`。
5. 如果作文不属于当前用户，返回现有 `DOC_FORBIDDEN`。
6. 如果会话未关联到当前作文，也返回 `DOC_FORBIDDEN`。
7. Markdown 只包含写作教练对话，不包含整篇作文正文和评分记录。
8. 如果用户消息是内部 `[写作教练 Copilot 请求]` 格式，Markdown 中只提取 `[用户本轮问题]` 后面的可读内容。

Markdown 建议结构：

```markdown
# 写作教练对话 - 作文标题

## 会话信息

- 作文 ID：doc_xxx
- 会话 ID：conv_xxx
- 会话标题：写作教练：结尾修改
- 消息数：12
- 更新时间：2026-05-23 23:06

## 对话记录

### 用户

我这篇作文的问题主要在哪里？

### 写作教练

你的主要问题集中在三个地方……
```

#### 题目难度

中等

#### 验收标准

- owner 可以导出当前作文已关联的写作教练会话 Markdown。
- 非 owner 不能导出。
- 未关联到当前作文的会话不能导出。
- Markdown 不包含完整作文正文和评分记录。
- Markdown 不直接暴露完整内部 Copilot prompt。
- 单元测试覆盖成功和 forbidden 场景。

### 小题 B：Controller 暴露 Markdown 下载接口

#### 题目 Prompt（完成）

请在写作资产相关 API 下新增单段教练对话 Markdown 下载接口。

建议接口：

```http
GET /api/writing/documents/{docId}/coach-conversations/{conversationId}/markdown
```

要求：

1. 从当前请求读取 `userId`。
2. 未登录返回 401。
3. 调用服务层导出单段写作教练对话 Markdown。
4. 响应 `Content-Type` 使用 `text/markdown; charset=UTF-8`。
5. 响应头包含 `Content-Disposition`，文件名建议：

```text
writing-coach-{docId}-{conversationId}.md
```

6. 不影响现有：
   - `GET /api/writing/documents/{docId}/asset`
   - `GET /api/writing/documents/{docId}/asset/markdown`
   - `POST /api/writing/documents/{docId}/asset/refresh`

#### 题目难度

简单

#### 验收标准

- 接口返回 `text/markdown`。
- 下载文件名包含 `docId` 和 `conversationId`。
- 未登录返回 401。
- 未授权场景按现有全局异常处理返回 forbidden。
- 原有资产详情和整份 Markdown 下载接口不回归。

## 题 2：前端写作教练历史对话按钮

### 发给 Trae 的 Prompt

请在用户中心作文资产详情中保留作文核心档案，同时在“写作教练对话”分区增加历史对话导出按钮。用户点击按钮后下载对应写作教练历史会话 Markdown。

### 小题 A：API 客户端新增教练对话 Markdown 下载方法

#### 题目 Prompt

请在前端写作 API 客户端中新增单段教练对话 Markdown 下载方法。

要求：

1. 方法名建议：

```ts
getWritingCoachConversationMarkdown(docId: string, conversationId: string): Promise<string>
```

2. 请求后端接口：

```http
GET /api/writing/documents/{docId}/coach-conversations/{conversationId}/markdown
```

3. `responseType` 使用 `text`。
4. 对 `docId` 和 `conversationId` 做 URL encode。
5. 不修改现有整份作文资产 Markdown 下载方法。

#### 题目难度

简单

#### 验收标准

- API 方法能拿到纯 Markdown 文本。
- `conversationId` 中包含特殊字符时不会破坏 URL。
- 现有 `getWritingDocumentAssetMarkdown` 仍可用。

### 小题 B：资产详情中增加历史对话导出按钮

#### 题目 Prompt（完成）

请修改用户中心作文资产详情页的“写作教练对话”分区。

要求：

1. 作文核心数据仍然保留，包括：
   - 题目信息
   - 作文正文
   - 评分记录
   - 整份 Markdown 档案
2. “Markdown 档案”区仍用于整篇作文资产，不要改成只放教练对话。
3. 在每个写作教练会话条目上增加按钮：

```text
下载对话 Markdown
```

4. 点击按钮后调用单段教练对话 Markdown 接口。
5. 前端生成 `.md` 文件并触发下载。
6. 下载文件名建议：

```text
writing-coach-{docId}-{conversationId}.md
```

7. 下载失败时展示错误提示。
8. 没有教练会话时继续显示“暂无写作教练对话”。

#### 题目难度

中等

#### 验收标准

- 有教练会话时，每条会话都有“下载对话 Markdown”按钮。
- 点击按钮会下载 `.md` 文件。
- 下载的文件只包含教练对话，不是整份作文档案。
- 没有教练会话时空状态正常。
- 作文正文、评分记录和整份 Markdown 档案仍然可见。

## 题 3：测试与文档

### 发给 Trae 的 Prompt

请为写作教练历史对话导出按钮补充必要测试，并同步更新作文资产文档，明确它和整份作文 Markdown 档案的区别。

### 小题 A：测试覆盖

#### 题目 Prompt

请补充后端测试和前端构建验证。

后端测试至少覆盖：

1. 当前用户可以导出自己作文下已关联的教练会话。
2. 当前用户不能导出未关联到该作文的教练会话。
3. 导出的 Markdown 会清理内部 Copilot prompt，只展示可读用户问题。
4. 导出的 Markdown 不包含整篇作文正文和评分记录。

前端验证至少运行：

```powershell
cd web
npm run build
```

#### 题目难度

中等

#### 验收标准

- 后端相关测试通过。
- 前端构建通过。
- 下载按钮没有造成 TypeScript 类型错误。
- 无会话和有会话两种 UI 状态都能正常展示。

### 小题 B：更新作文资产文档

#### 题目 Prompt

请更新作文资产数据文档，说明“整份作文 Markdown 档案”和“单段写作教练对话 Markdown”的区别。

建议更新文档：

```text
docs/data/writing-document-assets.md
```

要求：

1. 在“写作教练对话”章节说明：
   - 资产详情仍保留作文核心数据。
   - 写作教练对话分区提供单段历史对话下载按钮。
   - 下载后的 Markdown 可用外部软件打开。
2. 在“相关接口”中补充：

```http
GET /api/writing/documents/{docId}/coach-conversations/{conversationId}/markdown
```

3. 不把该接口描述成直接打开本机软件。

#### 题目难度

简单

#### 验收标准

- 文档说明清楚两种 Markdown 的区别。
- 文档包含新接口。
- 文档没有承诺浏览器直接打开本机软件。
- `docs` 构建通过。
