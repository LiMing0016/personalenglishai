# 写作成长板块：单篇得分趋势与得分分布 Trae 实现题目

## 背景

写作 Dashboard 的“成长 / 激励”板块需要从普通得分折线图升级为更有教育产品感的成长模块。

新的设计方向：

- 左侧主卡：`单篇得分趋势`
- 右侧上卡：`得分分布`
- 右侧下卡：`本月目标`

核心原则：

- `单篇得分趋势` 每个点代表一篇作文的最新评分。
- 不展示目标线，不暗示每篇作文都必须达到固定分数。
- 图表背景按分数区间分层，让用户看到自己处于哪个成长阶段。
- `得分分布` 用环形图展示作文落在不同分数区间的占比。
- `本月目标` 继续展示完成篇数、连续写作和最长记录。

分数区间建议：

| 区间 | 文案 | 背景色 |
| --- | --- | --- |
| `<60` | 需要补基础 | `#F7D8D4` |
| `60-70` | 基础建立 | `#F3E0BD` |
| `70-80` | 稳定提升 | `#E7E8C8` |
| `80-90` | 良好 | `#D7EADD` |
| `90-100` | 优秀 | `#D8E6F2` |

图表库：

- 使用项目已有 ECharts。
- 不新增图表库。
- 不使用静态图片或手写 SVG 假图。

## 题目 1：定义成长板块数据结构

### Prompt

给写作 Dashboard 的成长板块设计一套稳定数据结构，支持单篇得分趋势、得分分布和本月目标。

要求：

1. 前端 TypeScript 类型和后端 DTO 字段保持一致。
2. 数据结构至少包含：
   - `essayScoreTrend`
   - `scoreDistribution`
   - `monthlyGoal`
   - `streak`
3. `essayScoreTrend` 的每个点代表一篇作文的最新评分。
4. `scoreDistribution` 按 `<60 / 60-70 / 70-80 / 80-90 / 90-100` 分桶。
5. 第一版允许 mock，但 mock 数据必须集中管理，不能散落在 Vue template 里。

### 验收标准

- 前端有清晰的 Growth 类型定义。
- 后端或 mock provider 有对应字段。
- `essayScoreTrend` 包含作文标题、写作模式、最新分、评分时间、较上一篇变化、AI建议。
- `scoreDistribution` 包含区间 label、min、max、count、percent、color。
- 空数据时字段结构稳定，不返回 null 断层。

## 题目 2：实现单篇得分趋势图

### Prompt

实现左侧主卡 `单篇得分趋势`。

目标：
让用户看到自己每一篇作文的最新评分变化，而不是周期平均分。

要求：

1. 使用 ECharts LineChart。
2. 标题：`单篇得分趋势`。
3. 副标题：`每个点代表一篇作文的最新评分`。
4. 横坐标建议显示：
   - `第1篇`
   - `第2篇`
   - `第3篇`
   - ...
5. 纵坐标为 0-100。
6. 折线使用统一墨绿色，例如 `#0F8B6D`。
7. 点使用白底绿边圆点。
8. 最近一篇使用实心点。
9. 不展示目标线。
10. 没有足够数据时展示空状态文案。

### 验收标准

- 每个点代表一篇作文，不是按日期聚合。
- 图表不出现 80 分目标线。
- 最近一篇有明显但不突兀的视觉强调。
- 数据少于 2 篇时有合理空状态。
- ECharts 实例在组件卸载时 dispose。
- resize 时图表能自适应。

## 题目 3：增加分数区间背景层

### Prompt

给 `单篇得分趋势` 增加分数区间背景，让用户能直观看到分数处于哪个阶段。

要求：

1. 使用 ECharts 的 `markArea` 或等价能力实现区间背景。
2. 区间分为：
   - `<60`：需要补基础
   - `60-70`：基础建立
   - `70-80`：稳定提升
   - `80-90`：良好
   - `90-100`：优秀
3. 背景颜色使用低饱和学院风色彩。
4. 区间标签要轻，不要抢折线注意力。
5. 不要使用红绿强对比，不要做成考试告警图。

### 验收标准

- 趋势图背景能看到 5 个分数区间。
- 区间颜色从低分到高分有自然递进。
- 折线仍是视觉主角。
- 区间标签不遮挡数据点。
- `npm run build` 通过。

## 题目 4：优化 Tooltip 与关键点标记

### Prompt

优化单篇得分趋势的 tooltip 和关键点标记。

要求：

1. tooltip 展示：
   - 作文标题
   - 写作模式：自由 / 考试
   - 最新得分
   - 较上一篇变化：+6 / -2 / 持平
   - 评分时间
   - AI建议
2. 最高分点使用小徽章标记，例如 `最高92`。
3. 最近一篇用实心点标记。
4. 不要给每个点都加箭头或徽章。
5. 最高分和最近一篇如果是同一个点，视觉不要重叠混乱。

### 验收标准

- tooltip 信息比原来更完整。
- 最高分徽章存在但不喧宾夺主。
- 最近一篇有明确标记。
- 图表没有大量杂乱标注。
- 空 AI建议时不显示 undefined。

## 题目 5：实现得分分布环形图

### Prompt

实现右侧上方 `得分分布` 卡片，用环形图展示用户作文在不同分数区间的占比。

要求：

1. 使用 ECharts PieChart，设置为 donut chart。
2. 标题：`得分分布`。
3. 副标题：`全部作文 · 最新评分`。
4. 分桶：
   - `<60`
   - `60-70`
   - `70-80`
   - `80-90`
   - `90-100`
5. 环形图中心展示：
   - `80+`
   - 80 分以上作文占比，例如 `62%`
6. 下方展示区间列表：
   - 区间
   - 阶段文案
   - 篇数
   - 占比
7. 颜色和左侧分数区间背景保持同一套语义，但环形图颜色可以略深一点。

### 验收标准

- 环形图能正确展示各区间占比。
- 中心能看到 80+ 占比。
- 下方列表和图表数据一致。
- tooltip 展示区间、篇数、占比。
- 没有数据时显示“完成评分后展示得分分布”。

## 题目 6：优化本月目标与连续写作卡

### Prompt

优化右侧下方 `本月目标` 卡片，让它和成长板块整体风格一致。

5. 视觉上保持米白卡片、低饱和绿色进度条。

### 验收标准

- 本月目标卡能清楚看到完成进度。
- 连续写作和最长记录都存在。
- “还差几篇”文案计算正确。
- 目标卡不干扰单篇得分趋势图。
- 小屏幕下卡片不溢出。

## 推荐执行顺序

1. 先定数据结构和 mock。
2. 再做单篇得分趋势。
3. 再加分数区间背景。
4. 再做 tooltip 和最高分 / 最近篇标记。
5. 再做得分分布环形图。
6. 再优化本月目标。
7. 最后整合布局和补测试。

## 暂不做内容

- 不接复杂真实 AI 分析。
- 不改写作评分算法。
- 不改作文编辑器。
- 不改历史作文列表接口主流程。
- 不把本月目标叠加进单篇得分趋势图。
- 不新增第三方图表库或 UI 组件库。
