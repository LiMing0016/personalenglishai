# 学习材料高质量解析闭环生产级题目

## 背景

当前沉浸式学习平台已经具备 PDF 上传、OCR 基础解析、PDF 学习画布和右侧 Agent 面板雏形，但距离 NotebookLM / Acrobat AI 这类产品的学习材料问答闭环还有明显差距。

本题单按生产级功能拆分，目标不是一次性做成完美 PDF 解析器，而是把学习材料从“能解析一点文本”推进到“可预览、可定位、可检索、可引用、可让 Agent 基于资料回答”。

每道题只要求包含核心实现方向和验收标准，具体技术方案可以由实现者根据现有代码决定，但不能破坏现有 PDF 上传、精读工作台、OCR 服务和 Agent 面板。

---

## 题目 1：PDF 原文持久化与刷新后稳定预览

### Prompt（完成）

请完善 PDF 原文持久化能力。用户上传 PDF 后，系统必须保存原始文件，并允许前端在刷新页面、重新进入工作台、切换页面后继续加载 PDF 原貌。

前端不能只依赖临时 `blob:` 地址或 localStorage 保存 PDF 原文。后端需要提供稳定的 PDF 文件访问接口，并保证文档权限、文件元数据和异常兜底完整。

### 验收标准

- 上传 PDF 后，后端保存原始 PDF 文件和文件元数据。
- 刷新页面后，PDF 学习画布仍能显示原貌。
- 重新进入同一个文档工作台后，PDF 原文仍能加载。
- PDF 文件接口具备登录和文档归属权限校验。
- 原始文件不存在或读取失败时，前端显示明确提示，不白屏。
- 不再因为大 PDF 写入 localStorage 导致 quota 报错。

## 题目 2：PDF 内置目录读取

### Prompt（完成）

请实现 PDF 内置目录读取能力，优先读取 PDF 自带 bookmarks / outline，生成可用于左侧导航的章节树。

如果 PDF 本身存在目录结构，系统应优先使用原生目录，而不是仅依赖 OCR 文本块或页面段落猜测。

### 验收标准

- 能读取包含 bookmarks / outline 的 PDF。
- 左侧目录能展示章节标题、层级和跳转页码。
- 点击目录节点后，PDF 学习画布跳转到对应页。
- 没有内置目录的 PDF 不报错，应进入后续兜底目录生成逻辑。
- 目录数据保存到后端响应或知识结构中，刷新后仍可使用。

---

## 题目 3：目录页识别与章节树生成

### Prompt（完成）

请实现目录页识别能力。对于没有内置目录的 PDF，系统应自动识别“目录”页，根据目录页内容生成章节树。

该能力需要适配常见中文教材、英文教材、论文资料和考试资料中的目录页格式。

### 验收标准

- 能识别常见“目录 / Contents / Table of Contents”页面。
- 能从目录页中提取章节标题和页码。
- 能生成多级章节树。
- 能处理目录跨多页的情况。
- 目录页识别失败时，应降级为标题识别或普通页面导航。
- 左侧导航不再显示大量无意义的 `P1 / P2 / P3` 作为主要目录。

---

## 题目 4：文档版面元素标准化

### Prompt（完成）

请统一学习材料解析后的元素模型，把 PDF 中的标题、正文、图片、表格、公式、页眉页脚、页码等内容转换为标准化文档元素。

每个元素都应保留页码、阅读顺序、bbox、文本内容、元素类型和来源，供后续目录生成、chunk 检索、Agent 引用和前端高亮使用。

### 验收标准

- 后端有统一的文档元素模型。
- 元素至少包含 `documentId`、`pageNumber`、`elementId`、`type`、`text`、`bbox`、`order`、`source`。
- 标题、正文、图片、表格、公式至少能在数据结构上区分。
- 普通 OCR 文本也必须映射为标准元素。
- 前端能基于元素定位当前页和当前选区。
- 不同解析来源的元素格式保持一致。

---

## 题目 5：OCR 质量诊断与降级策略

### Prompt（完成）

请实现 OCR 和文本层解析质量诊断。系统需要判断页面是否存在乱码、重复文本、低置信度、阅读顺序混乱、空白页、扫描质量差等问题，并给出可解释的 warnings。

当文本层质量差时，应自动切换或建议切换到 OCR；当 OCR 质量差时，应保留问题页信息，避免把低质量文本直接当作可靠知识喂给 Agent。

### 验收标准

- 能识别乱码文本层和明显异常字符。
- 能识别重复拼接、空白页、低置信页。
- 每页有质量诊断结果和 warning。
- 前端能看到当前文档或当前页的解析质量提示。
- 低质量内容不会直接作为高置信 source chunk。
- 质量诊断结果可用于后续重新解析或人工排查。

---

## 题目 6：图片与图表资产抽取

### Prompt（完成）

请实现 PDF 中图片、插图、图表的资产抽取能力。系统需要把图片区域识别为独立学习资产，并和页码、bbox、上下文文本建立关联。

该能力不要求第一版完成复杂视觉理解，但必须为后续图表解释、图片引用和 Agent 回答打好数据基础。

### 验收标准

- 能识别 PDF 页面中的图片或图表区域。
- 图片资产保存时包含 `documentId`、`pageNumber`、`assetId`、`bbox`、`assetType`。
- 图片与附近标题、图注或正文建立上下文关系。
- 前端可以知道某一页有哪些图片资产。
- Agent 后续回答时可以引用图片所在页和位置。
- 不把图片区域误拼成大段乱码文本。

---

## 题目 7：表格结构化识别

### Prompt（完成）

请实现表格识别与结构化保存能力。PDF 中的表格不应被简单拼成乱码文本，而应尽量保留行、列、单元格、标题和页码定位。

第一版可以允许部分表格降级为文本，但必须明确标记表格区域和降级原因。

### 验收标准

- 能识别常见表格区域。
- 表格元素能保存行列结构或结构化文本。
- 表格保留页码和 bbox。
- 表格识别失败时返回 warning，不生成混乱正文。
- 前端能把表格和普通段落区分展示。
- Agent 回答表格相关问题时能引用表格来源。

---

## 题目 8：公式识别与结构化保存

### Prompt（完成）

请实现公式识别能力。PDF 中的数学公式、代码公式或符号表达式应尽量保留为 LaTeX 或结构化文本，不应被普通 OCR 识别成乱码。

对于无法可靠识别的公式，应保留公式区域、图片资产和 warning，供后续人工或视觉模型补充。

### 验收标准

- 能识别页面中的公式区域。
- 公式元素保留页码、bbox、原始文本或 LaTeX。
- 公式识别失败时不污染正文 chunk。
- 公式区域可以被前端定位和高亮。
- 公式数据能进入后续知识检索或 Agent 引用链路。
- 中英文教材、数学资料、技术文档中公式不会被大面积识别为乱码正文。

---

## 题目 9：Source Chunk 检索与 Agent 基于资料回答

### Prompt（要求）

请实现基于 source chunks 的 Agent 问答能力。用户在学习材料中提问时，Agent 应优先检索当前 PDF 的相关片段，并基于片段内容回答，而不是只做通用聊天。

回答应明确依赖哪些资料片段，支持后续引用定位和前端跳转。

### 验收标准

- 文档元素可以生成可检索 source chunks。
- chunk 保留 `documentId`、`pageNumber`、`elementId`、`bbox` 和原文内容。
- Agent 回答时会检索当前文档相关 chunk。
- 回答不能脱离 source 内容胡乱扩展。
- 回答结果包含引用来源列表。
- 当前选区提问时，应优先使用当前选区和邻近 chunk。

---

## 题目 10：PDF 选区联动 Agent 与引用定位展示

### Prompt（完成）

请打通 PDF 选区和右侧 Agent 面板。用户在 PDF 学习画布中选择一段内容时，右侧 Agent 应知道当前选区的文档、页码、元素、bbox 和文本内容，并基于当前选区进行讲解、翻译、提炼表达或整理笔记。

Agent 回答后，前端需要展示引用定位，用户可以点击引用回到 PDF 对应页和区域。

### 验收标准

- 前端选择 PDF 内容后，右侧面板显示当前选区上下文。
- 选区数据包含 `documentId`、`pageNumber`、`elementId`、`bbox`、`selectedText`。
- 点击“解释段落 / 提取表达 / 整理笔记 / 问 Agent”时，请求携带选区上下文。
- Agent 回答基于当前选区和相关 source chunks。
- 回答中展示引用页码和片段来源。
- 点击引用后，PDF 学习画布跳转并高亮对应区域。
- 刷新页面后，不应丢失文档级上下文。

---

## 推荐实施顺序

1. 题目 1：PDF 原文持久化与刷新后稳定预览
2. 题目 2：PDF 内置目录读取
3. 题目 3：目录页识别与章节树生成
4. 题目 4：文档版面元素标准化
5. 题目 5：OCR 质量诊断与降级策略
6. 题目 9：Source Chunk 检索与 Agent 基于资料回答
7. 题目 10：PDF 选区联动 Agent 与引用定位展示
8. 题目 6：图片与图表资产抽取
9. 题目 7：表格结构化识别
10. 题目 8：公式识别与结构化保存

优先级说明：先保证 PDF 原文、目录、元素、质量诊断和 Agent 问答闭环；图片、表格、公式属于高质量解析增强，可以在主链路稳定后逐步补齐。
