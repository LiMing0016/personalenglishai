# 翻译中心 Hub 首页实现题目

## 背景

当前项目已有独立翻译页 [TranslationPage.vue](F:/personalenglishai/web/src/pages/app/TranslationPage.vue)，但页面仍偏向普通文本翻译。下一步先不做沉浸式阅读工作台，也不做 PDF 解析和后端翻译会话，而是先把 `/app/translation` 重做为“翻译中心 Hub”。

Hub 的目标是让用户进入翻译模块后能完成四件事：

- 继续上次翻译学习。
- 找到适合自己学段和目标的素材。
- 管理自己的翻译记录和笔记。
- 通过 `新建翻译` 进入后续沉浸式翻译流程。

产品特色不是做另一个通用翻译器，而是做学习型翻译中心：把英文材料转化为笔记、词汇、句型、复习卡片和写作素材。

参考文件：

- `docs/superpowers/specs/2026-06-08-translation-hub-design.md`
- `web/src/pages/app/TranslationPage.vue`
- `web/src/router/index.ts`
- `web/AGENTS.md`

本轮不要求：

- 实现 PDF 高质量解析。
- 实现 OCR。
- 实现沉浸式双语阅读工作台。
- 实现真实素材库后端。
- 抓取经济学人、外刊、期刊全文。

## 题目 1：重构 `/app/translation` 为翻译中心 Hub 首页

题目类型：feature 迭代

难度：中等

### A 小题：实现 Hub 顶部和新建翻译入口

#### Prompt

请把 `/app/translation` 从普通翻译输入页重构为“翻译中心”首页。顶部区域至少包含：

- 标题：`翻译中心`
- 副标题：`找到素材，继续阅读，整理你的双语学习笔记`
- 主按钮：`新建翻译`

`新建翻译` 点击后打开下拉或弹窗，入口中至少包含：

- 上传 PDF / TXT / MD。
- 粘贴文本。
- 模式选择：沉浸阅读 / 考试翻译。
- 开始按钮。

要求：

1. 上传和配置不要常驻在首页左侧或主区域。
2. 首页不要做大 Hero，不要做营销页。
3. 快速翻译模式不放在翻译中心，短句翻译由 AI 助手承担。
4. 考试类型不要重复选择，后续按用户学段和材料类型处理。

#### 难度

中等

#### 验收标准

- 打开 `/app/translation` 后能看到“翻译中心”标题和副标题。
- `新建翻译` 是页面最明确的主操作。
- 点击 `新建翻译` 能看到上传、粘贴、模式选择入口。
- 页面上不再出现旧的左右文本翻译器作为主体验。
- 上传配置不是常驻大面板，首页保持 Hub 仪表盘感。

### B 小题：搭建 Hub 基础响应式布局

#### Prompt

请为翻译中心搭建基础布局。桌面端建议使用主内容区 + 右侧栏：

- 主内容区包含继续学习、素材库、我的翻译。
- 右侧栏包含今日推荐、笔记摘要、最近笔记和新手引导。

要求：

1. 页面密集但清晰，像学习中心，不像表单页。
2. 卡片圆角控制在 8px 左右，避免过度装饰。
3. 颜色以白、浅灰、青绿色为主，少量使用蓝色或橙色标签。
4. 移动端可以纵向堆叠，但不能文本重叠或按钮溢出。

#### 难度

中等

#### 验收标准

- 桌面端能看到主内容区和右侧栏。
- 页面模块层级清楚，不显得像普通翻译工具。
- 窄屏下模块能纵向排列，没有明显重叠。
- 按钮、标签、表格文本不溢出容器。

## 题目 2：实现“继续学习”模块

题目类型：feature 迭代

难度：中等

### A 小题：实现最近翻译项目卡片

#### Prompt

请在翻译中心首页实现“继续学习”模块，展示最近 3 个翻译项目卡片。可以先使用前端 mock 数据。

每张卡片至少包含：

- 封面或来源图标。
- 标题。
- 副标题或来源说明。
- 来源类型：PDF / 用户导入 / 素材库。
- 当前进度：页码、段落或题目进度。
- 进度条和百分比。
- 标签：有笔记、考试翻译、写作素材等。
- 操作按钮：继续阅读。

#### 难度

中等

#### 验收标准

- “继续学习”模块位于首屏显著位置。
- 至少展示 3 个 mock 翻译项目。
- 每张卡片都有进度、标签和继续阅读按钮。
- 卡片内容不会因为标题较长而压坏布局。
- 点击继续阅读有明确交互反馈，可以暂时 toast 或跳转占位。

### B 小题：补充空状态和查看全部入口

#### Prompt

请为“继续学习”模块补充空状态和 `查看全部` 入口。

要求：

1. 没有最近记录时，引导用户点击 `新建翻译` 或从素材库开始。
2. `查看全部` 可以暂时滚动到“我的翻译”模块或保留占位行为。
3. 空状态不能是一片空白。

#### 难度

简单到中等

#### 验收标准

- recent sessions 为空时页面仍有清晰引导。
- `查看全部` 有可感知反馈。
- 空状态文案突出“开始一次翻译学习”，不是普通错误提示。

## 题目 3：实现“素材库”模块

题目类型：feature 迭代

难度：中等

### A 小题：实现学习素材分类卡片

#### Prompt

请在翻译中心首页实现“素材库”模块。首版用前端 mock 数据展示以下 6 个入口：

- 经济学人
- 外刊新闻
- 学术期刊
- 考试材料
- 技术文档
- 用户导入

每个卡片至少包含：

- 图标或视觉符号。
- 类别名称。
- 简短说明。
- 适合能力：阅读、写作素材、词汇积累、考试拆题等。
- 难度。
- 预计阅读时长。
- 素材数量或“我的导入”说明。

要求：

1. 不要在首版展示受版权保护的正文内容。
2. 经济学人、外刊、期刊只作为素材入口和学习方向，不做全文抓取。
3. 页面文案要体现学习策划能力，而不是简单分类导航。

#### 难度

中等

#### 验收标准

- 素材库展示 6 个分类入口。
- 每个入口都包含难度、阅读时长或素材数量信息。
- 文案体现“适合练什么能力”。
- 不出现外部文章全文或误导性版权内容。

### B 小题：实现素材卡片交互反馈

#### Prompt

请为素材库卡片补充基础交互。

要求：

1. 点击素材分类后可以展示 toast、打开占位列表，或切换到该分类的占位状态。
2. `用户导入` 点击后应打开 `新建翻译` 入口。
3. 鼠标 hover 和键盘 focus 状态清晰。

#### 难度

简单到中等

#### 验收标准

- 点击每个素材分类都有反馈。
- 点击 `用户导入` 能打开新建翻译入口。
- 卡片 hover/focus 状态清楚。
- 交互不会触发不存在的真实抓取接口。

## 题目 4：实现“我的翻译”记录列表

题目类型：feature 迭代

难度：中等偏难

#### Prompt

请在翻译中心首页实现“我的翻译”模块。首版可使用前端 mock 数据。

列表字段至少包含：

- 标题。
- 来源类型。
- 翻译模式：沉浸阅读 / 考试翻译。
- 更新时间。
- 笔记数量。
- 阅读进度。
- 状态：阅读中 / 已完成。
- 操作：继续阅读 / 查看笔记。

要求：

1. 桌面端可以使用表格。
2. 窄屏下可以改为列表卡片。
3. 操作按钮不应挤压标题内容。

#### 难度

中等

### B 小题：实现搜索和筛选

#### Prompt

请为“我的翻译”模块实现前端搜索和筛选。筛选项包括：

- 全部
- 阅读中
- 已完成

- 考试模式

要求：

1. 搜索和筛选可以先基于 mock 数据本地计算。
2. 空结果要有提示。
3. 当前筛选项要有明显激活状态。

#### 难度

中等

#### 验收标准

- 点击筛选项后列表内容变化。
- 输入关键词后列表可过滤。
- 搜索无结果时有空状态。
- 筛选和搜索组合使用时行为稳定。

## 题目 5：实现右侧学习摘要栏

题目类型：feature 迭代

难度：中等

### A 小题：实现今日推荐和笔记摘要

#### Prompt

请在翻译中心右侧栏实现“今日推荐”和“我的笔记摘要”。

今日推荐至少包含 3 条推荐素材：

- 来源。
- 标题。
- 预计阅读时长。
- 难度。
- 收藏或稍后读入口。

我的笔记摘要至少包含：

- 翻译篇数。
- 阅读时长。
- 笔记数量。

1. 推荐文案要体现“根据学段/学习目标推荐”的感觉，但首版可以使用 mock 数据。
2. 不要在右侧栏放复杂配置表单。
3. 统计卡片要紧凑，不能抢主内容区注意力。

#### 难度

中等

#### 验收标准

- 右侧栏能展示今日推荐和笔记摘要。
- 推荐素材至少 3 条。
- 笔记摘要至少 6 个统计项。
- 右侧栏在桌面端不挤压主内容区。

### B 小题：实现最近笔记和新手引导

#### Prompt

最近笔记至少展示 3 条：

- 笔记标题。

- 更新时间。

新手引导至少包含：

- 新建翻译。

#### 难度

简单到中等

#### 验收标准

- 最近笔记列表可见且信息完整。
- 新手引导能触发 `新建翻译` 或定位到素材库/继续学习模块。
- 右侧栏整体信息密度适中，没有过多装饰。

- `recentSessions`
- `materialCategories`
- `myTranslations`

中等

## 总体验收标准

完成本题后，应满足：

1. `/app/translation` 已成为翻译中心 Hub 首页。
2. 首页包含顶部、新建翻译、继续学习、素材库、我的翻译、右侧学习摘要。
3. 页面体现 PEAI 的学习型翻译特色，而不是普通通用翻译器。
4. 上传和模式配置只在 `新建翻译` 中出现，不常驻主页面。
5. 首版使用 mock 数据即可，但数据结构和组件边界便于后续接真实接口。
6. 不实现网页抓取，不抓取外部报刊全文。
7. 不影响写作页右侧翻译面板。
8. 前端构建通过，并有明确手动回归结果。
