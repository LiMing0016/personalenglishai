# 写作总览组件 Trae 实现题目

## 背景

写作练习首页当前顶部有 4 张独立统计卡：累计作文、评分次数、平均分、最高分。下一版希望合并成一个“写作总览”组件，用一个整体模块展示摘要、趋势图和 AI 建议。

目标组件结构：

- 顶部：标题、统计口径、右上角口径按钮。
- 中部：4 个摘要指标。
- 主图：ECharts 组合图。
- 底部：AI建议。

默认统计口径：

- 时间范围：近30天。
- 模式：全部模式。
- 评分口径：按每篇最新评分。

## 题目 1：写作总览数据结构与 mock 数据

### Prompt

实现写作总览组件的数据结构和 mock 数据。

目标：
在写作页中新增一个写作总览数据模型，用于支持“累计作文、评分次数、平均分、最高分、趋势图、AI建议”。

要求：

1. 数据先放在 `writingDashboardMock.ts` 里。
2. 数据包含：
   - `summary`: `totalEssays`, `totalSubmissions`, `averageScore`, `bestScore`
   - `trend`: `date`, `essayCount`, `submissionCount`, `averageScore`, `bestScore`
   - `insight`: AI建议文案
3. 默认口径为：近30天、全部模式、按每篇最新评分。
4. 不接后端接口，先 mock。

### 验收标准

- `writingDashboardMock.ts` 中有独立的 overview 数据。
- 数据能支持柱状图：新增作文、评分次数。
- 数据能支持折线图：平均分。
- 最高分不作为独立折线，只作为标注数据。
- AI建议字段存在，文案使用“AI建议”。

## 题目 2：实现写作总览组件外观

### Prompt

实现一个 `WritingOverviewCard` 组件，用于替换当前顶部 4 张统计卡。

目标：
把“累计作文、评分次数、平均分、最高分”合并到一个大卡片中展示。

要求：

1. 新建组件，建议放在 `src/components/writing/dashboard/WritingOverviewCard.vue`。
2. 卡片风格保持当前写作页米白 academy 风格。
3. 卡片顶部包含：
   - 标题：写作总览
   - 副标题：近30天 · 全部模式 · 按每篇最新评分
   - 右上角口径按钮：近30天 · 全部模式 ▾
4. 指标区横向展示 4 个摘要：
   - 累计作文 2 篇
   - 评分次数 1 次
   - 平均分 78 分
   - 最高分 92 分
5. 不实现下拉交互，只先做静态 UI。

### 验收标准

- 写作页顶部不再显示 4 张独立统计卡。
- 新卡片视觉上是一个整体模块。
- 4 个指标在卡片内部横向排列。
- 标题、副标题、右上角口径按钮都存在。
- 移动端不溢出，指标可换行或两列展示。

## 题目 3：接入 ECharts 组合图

### Prompt

在 `WritingOverviewCard` 中接入 ECharts 组合图。

目标：
用一张图展示作文数量、评分次数和平均分趋势。

要求：

1. 使用项目已有 `echarts`，不新增图表库。
2. 图表包含：
   - 绿色柱状图：新增作文
   - 米灰/浅棕柱状图：评分次数
   - 蓝色折线图：平均分
3. 使用双 Y 轴：
   - 左轴：篇数 / 次数
   - 右轴：分数 0-100
4. 最高分不画线，只在最高点附近显示 amber 标注：最高 92。
5. tooltip 展示日期、新增作文、评分次数、平均分、最高分。
6. 组件卸载时销毁 ECharts 实例，窗口 resize 时重绘。

### 验收标准

- 图表能正常渲染，不是 SVG 假图。
- 柱状图和折线图同时存在。
- 最高分以标注形式出现，不出现第二条最高分折线。
- tooltip 内容完整。
- `npm run build` 通过。

## 题目 4：增加底部 AI 建议区域

### Prompt

在写作总览卡片底部增加 AI建议 区域。

目标：
让写作总览不只是展示数据，还能给用户学习反馈。

要求：

1. 卡片底部增加一条浅色提示条。
2. 标题使用：AI建议。
3. 文案来自 `overview.insight`。
4. 示例文案：
   “本周期评分样本偏少，建议完成 3 次以上评分后观察趋势。”
5. 视觉要轻，不要做成强提示或警告。

### 验收标准

- 卡片底部显示“AI建议”。
- 建议文案来自 mock 数据。
- 样式与米白页面一致。
- 不使用“学习建议”这个标题。

## 题目 5：集成到写作页并补测试

### Prompt

把 `WritingOverviewCard` 集成到 `WritingPage` 的写作练习首页。

目标：
用新的写作总览组件替换当前顶部 4 个统计卡片。

要求：

1. 删除或隐藏原来的 `stats-grid` 四张卡片。
2. 在筛选区域下方展示 `WritingOverviewCard`。
3. 保留后面的成长 / 激励、写作能力、主题风格、历史作文模块。
4. 补充一个轻量测试，检查：
   - 页面包含“写作总览”
   - 页面包含“AI建议”
   - 页面包含 ECharts overview 组件相关 class 或组件名
   - 页面不再渲染原来的 `stats-grid` 四卡结构
5. 保持现有 `writingDashboardPrototype` 测试通过。

### 验收标准

- 写作页顶部视觉变成一个完整写作总览卡片。
- 原 4 张统计卡不再出现。
- 后续模块布局不受影响。
- `node tests/writingDashboardPrototype.test.ts` 通过。
- `npm run build` 通过。

## 推荐执行顺序

1. 先做数据结构和 mock 数据。
2. 再做静态卡片 UI。
3. 再接 ECharts 组合图。
4. 再加 AI建议。
5. 最后集成到写作页并补测试。
