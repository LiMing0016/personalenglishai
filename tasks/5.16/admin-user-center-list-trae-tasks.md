# Admin 用户中心列表页前端 Trae 题目

## 背景

用户中心列表页是管理员找人的入口，不是数据库全字段镜像。页面需要接近 Figma 中左侧截图：顶部标题和筛选卡，中间轻量表格，右侧摘要抽屉由另一个题目承接。

目标路由：

```text
/admin/users
```

主要文件：

- `web/src/pages/admin/AdminUsersPage.vue`
- `web/src/api/admin.ts`

## 题目 1：用户中心筛选卡

难度：中等

### Prompt

请改造 `/admin/users` 页面顶部筛选区，使其符合 Admin 用户中心 Figma 设计中的“紧凑筛选卡”样式。筛选区需要支持管理员按用户身份、账号状态、学习阶段、角色、订阅和时间范围快速定位用户。

筛选项：

- 关键词：昵称、邮箱、手机号。
- 用户 ID。
- 状态：全部、active、disabled。
- 学段：全部、ielts、toefl、postgrad、kaoyan、gaokao。
- 账号角色：全部、user、admin。
- 管理员角色：全部、super_admin、support_admin、content_admin。
- 当前套餐：全部、free、basic、pro、premium。
- 订阅状态：全部、free、active、expired。
- 是否超额：全部、已超额、未超额。
- 注册时间范围。
- 最近活跃时间范围。

### 验收标准

- 筛选区是一个独立卡片，不和表格混在一起。
- 桌面端至少 4 列布局，窄屏自动换行。
- 查询按钮和重置按钮固定在标题区右侧或筛选区右侧，位置稳定。
- 点击查询时回到第一页。
- 点击重置时清空全部筛选并重新加载。
- 空筛选项不会传给后端。
- 日期范围转换为后端可识别的开始/结束参数。
- 加载中不导致筛选区整体消失。

## 题目 2：用户轻量表格

难度：中等

### Prompt

请改造 `/admin/users` 表格，使其只展示用户中心高频排查字段。表格视觉需要接近 Figma：行高紧凑、身份信息上下两行展示、状态使用标签、额度使用用细进度条表达。

表格字段：

- ID。
- 用户：头像缩写、昵称、邮箱或手机号。
- 状态/学段。
- 角色：账号角色、管理员角色。
- 订阅：套餐、订阅状态、额度周期。
- 额度：已用、上限、剩余、进度条、超额状态。
- 注册时间。
- 最近活跃。
- 操作：查看详情。

### 验收标准

- 一行能清楚看出用户身份、状态、角色、套餐和额度。
- 状态 `active` 使用绿色标签。
- 状态 `disabled` 使用红色标签。
- 学段和管理员角色使用中性或蓝色标签。
- 额度进度条不会撑高表格。
- 超额用户的进度条或提示使用红色。
- 空字段显示 `-`。
- 表格空结果显示空状态，不显示空白页面。
- 表格接口失败时显示错误提示和重试入口。
- 点击“查看详情”进入 `/admin/users/:id`。

## 题目 3：分页、加载和移动端适配

难度：中等

### Prompt

请完善用户列表页的分页、加载态、错误态和响应式表现。该页面是管理员日常高频页面，不能因为数据为空、接口慢、窗口变窄就破坏布局。

### 验收标准

- 默认每页 10 条。
- 显示总条数、当前页、上一页、下一页。
- 第一页禁用上一页。
- 最后一页禁用下一页。
- 加载中表格区域显示加载文案或骨架态。
- 接口失败显示错误提示和重试按钮。
- 空结果显示“当前筛选无匹配用户”，并提供重置筛选动作。
- 宽屏展示表格 + 右侧抽屉空间。
- 窄屏时表格可横向滚动或布局降级，不发生文字重叠。

## 题目 4：前端类型和 API 参数整理

难度：简单

### Prompt

请整理 `web/src/api/admin.ts` 中 Admin 用户列表相关类型，保证页面筛选参数、列表项字段和后端响应一致。不要使用大面积 `any` 逃避类型。

### 验收标准

- 用户列表 item 类型包含账号、状态、角色、订阅、额度、时间字段。
- 查询参数类型覆盖页面所有筛选项。
- 额度相关字段允许后端返回数字或空值，但页面格式化后稳定展示。
- `npm run build` 通过。
