# 学习提醒与任务日历系统 Trae 题目

## 背景

当前项目已经具备写作、单词学习、翻译、学习广场、知识图谱等学习模块，但用户每天要做什么、哪些任务逾期、哪些任务可以补做、连续学习如何统计，还缺少统一调度。新的目标是建设“学习提醒与任务日历系统”，把每日复习、写作、阅读、翻译、打卡、模考、知识图谱复习和 AI 学习计划统一到一个任务日历中。

该需求不是一个简单日历组件，而是跨数据库、任务生成、提醒策略、状态同步、前端日历、AI 计划、统计分析和权限安全的系统级功能。所有题目都应避免单文件修改，每题至少涉及数据库、后端、前端、调度、测试或文档中的两类以上改动。

## 题目类型范围

- 0-1代码生成
- feature迭代
- bug修复
- 工程化
- 代码测试

## 题目 1：学习任务与日历领域模型设计

题目类型：0-1代码生成

### A 小题：设计统一学习任务表

#### 题目 Prompt

请设计并实现统一学习任务数据模型。

至少新增：

- `learning_task`
- `learning_task_schedule`
- `learning_task_status_log`
- `learning_task_source_link`

任务类型至少支持：

- `vocabulary_review`
- `vocabulary_new`
- `writing_practice`
- `writing_review`
- `reading`
- `translation`
- `mock_exam`
- `community_checkin`
- `knowledge_graph_review`
- `custom`

要求：

- 每个任务必须归属 userId。
- 支持计划日期、开始时间、截止时间、优先级、来源模块、来源 ID。
- 状态支持 `pending`、`in_progress`、`completed`、`skipped`、`overdue`、`rescheduled`、`cancelled`。
- migration 和 `schema.sql` 同步。

#### 题目难度

高

#### 验收标准

- 新增表结构完整。
- 支持按用户、日期、状态、任务类型查询。
- 状态变更写入 status log。
- 后端测试覆盖创建任务、状态变更和来源关联。

### B 小题：设计任务重复规则和实例化机制

#### 题目 Prompt

请设计学习任务的重复规则和实例化机制。

要求：

- 支持一次性任务、每日、每周、自定义间隔。
- 重复规则和具体任务实例分离。
- 只生成未来一定窗口内的实例，避免无限写库。
- 支持暂停和恢复重复任务。
- 任务实例生成需要幂等。

#### 题目难度

高

#### 验收标准

- 每日任务可以生成未来 7 天实例。
- 重复生成不会产生重复实例。
- 暂停规则后不再生成新任务。
- 测试覆盖每日、每周、自定义间隔。

## 题目 4：AI 学习计划 Agent 接入

题目类型：0-1代码生成

### A 小题：实现任务计划 Agent

#### 题目 Prompt

请实现学习任务计划 Agent，用于在规则生成的基础上解释和调整每日任务。

要求：

- Agent 输入包括用户近期学习数据、任务候选、完成率、薄弱点。

#### 题目难度

极高

#### 验收标准

- Agent 可生成每日计划解释。
- 模型失败时规则任务仍可用。
- Agent 输出 parse 失败有错误记录。
- 测试覆盖 Agent 成功、失败和降级。

### B 小题：实现 AI 计划确认和用户反馈

#### 题目 Prompt

要求：

- 用户可以调整任务顺序、删除建议任务、修改时间。
- 用户反馈“太多 / 太少 / 不适合”写入后端。
- 后续生成计划时参考用户反馈。

#### 题目难度

高

#### 验收标准

- AI 计划可确认。
- 用户调整后保存为真实任务。
- 反馈会影响后续计划。
- 测试覆盖确认、调整和反馈。

## 总体验收标准

- 不允许单文件完成题目；每题必须涉及跨层改动或配套测试。
- 所有任务必须按 userId 隔离，不允许跨用户访问或来源跳转。
- 任务生成必须幂等，不能重复生成大量同类任务。
- 状态变更必须有日志，方便排查。
- AI 计划必须可关闭，规则引擎必须能独立运行。
- 提醒系统必须避免重复提醒和敏感内容泄露。
- 前端必须有空状态、加载态、错误态、无权限态。
- 日历查询必须考虑性能，不允许月视图逐日循环查库。
- 文档必须说明任务状态流、生成规则、提醒策略和灰度开关。

## 推荐实现顺序

1. 题目 1-3：先完成任务模型、来源接入和每日生成引擎。
2. 题目 4-6：接入 AI 计划、API 契约、偏好和提醒设置。
3. 题目 7-10：实现用户日历、今日工作台、延期补做和统计。
4. 题目 11-15：实现提醒、浏览器通知、自定义任务、AI 总结和排程。
5. 题目 16-18：实现阶段目标、后台调试、一致性校验。
6. 题目 19-22：补性能、安全、导出、测试和灰度上线。
